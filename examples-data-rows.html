Data Rows

Nowoczesna alternatywa dla tabel oparta na CSS Grid i Flexboksie — idealna do list klientów, projektów i plików w systemach CRM.

Wiersze Danych (Data Rows)

Klasa .data-row wykorzystuje CSS Grid do ułożenia elementów w szerokich wierszach — świetna alternatywa dla tabel w CRM-ach.

<!-- Wiersz oparty na CSS Grid -->
<div class="data-row">
  <div class="fw-bold">Nazwa Projektu</div>
  <div class="text-muted">Parametry</div>

  <!-- Kropka statusu -->
  <div><span class="status-dot status-pending">Oczekuje</span></div>

  <!-- Przyciski akcji (Z pionowymi separatorami) -->
  <div class="data-row-actions btn-action-group with-dividers">
    <button class="btn-action">Edytuj</button>
    <button class="btn-action text-danger">Usuń</button>
  </div>
</div>

Kompaktowe Wiersze (List Items)

Wariant .data-row-compact oparty na Flexboksie. Idealny do bocznych paneli, list plików do pobrania czy powiadomień.

<div class="card border-0 shadow-sm">

  <!-- Kompaktowy wiersz -->
  <div class="data-row-compact">

    <!-- Ikona (dodaj .icon-square dla kwadratu) -->
    <div class="row-icon icon-square bg-danger text-white">
      <i class="icon-file-text"></i>
    </div>

    <!-- Treść (Automatycznie ucina za długi tekst) -->
    <div class="row-content">
      <div class="row-title">2026-raport.pdf</div>
      <div class="row-details">0.4 MB z 0.8 MB</div>
    </div>

    <!-- Akcje po prawej -->
    <div class="row-actions">
      <button class="btn btn-action"><i class="icon-x"></i></button>
    </div>

  </div>

</div>

Prosta Lista (List Group)

Gdy .data-row to za dużo, a zwykła <ul> to za mało — .list-group łączy pozycje w jeden spójny panel z ramkami między wierszami.

Ustawienia konta Powiadomienia Metody płatności Integracje API 
<div class="list-group">
  <a href="#" class="list-group-item is-active">Ustawienia konta</a>
  <a href="#" class="list-group-item">Powiadomienia</a>
  <a href="#" class="list-group-item">Metody płatności</a>
</div>
