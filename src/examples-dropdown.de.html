Dropdown

Ein einfaches Dropdown-Menü — null JavaScript, schließt sich automatisch bei Klick außerhalb. Zwei Varianten: die klassische auf Basis von <details> (Navbar) sowie ein Popover im Top Layer (überall dort, wo der Container den Inhalt abschneidet — Tabellen, Karten, Modale).

Einfaches Dropdown

<details class="dropdown"> + <summary class="dropdown-toggle"> als Auslöser, .dropdown-menu mit .dropdown-item-Links als Inhalt.

  <div class="dropdown-menu">

    <a href="#" class="dropdown-item">Duplizieren</a>
    <a href="#" class="dropdown-item">Archivieren</a>
  </div>
</details>

Dropdown als Popover (Top Layer)

Die empfohlene Variante außerhalb der Navbar: fügen Sie popovertarget="ID" zu einem beliebigen bestehenden Button hinzu sowie das Attribut popover plus dieselbe id zu .dropdown-menu. Das Menü wird im Top Layer gerendert (nicht durch overflow abgeschnitten — z. B. in einem .table-wrapper oder einem Modal) und verankert sich automatisch an seinem Button — ohne .dropdown-Wrapper.

Bearbeiten Duplizieren Archivieren
Bericht herunterladen Per E-Mail senden Löschen 
<!-- Ein beliebiger bestehender Button + popovertarget -->
<button class="btn btn-outline-dark" popovertarget="pop-menu">Optionen ▾</button>

<!-- [popover] = Top Layer: das Menü wird nicht durch overflow abgeschnitten -->
<div class="dropdown-menu" popover id="pop-menu">
  <a href="#" class="dropdown-item">Bearbeiten</a>
  <a href="#" class="dropdown-item">Duplizieren</a>
  <a href="#" class="dropdown-item">Archivieren</a>
</div>

<!-- Ausrichtung an der rechten Kante des Buttons -->
<div class="dropdown-menu dropdown-menu-end" popover id="pop-menu-2">...</div>
