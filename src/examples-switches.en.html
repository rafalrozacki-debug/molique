Three visual switch variants built on a native checkbox, with a forced 44px height for B2B accessibility.

Switches

Built on top of a native <input type="checkbox"> — available in default, square, and outline variants.

Default (iOS Style)

Square (.form-switch-square)

Outline (.form-switch-outline) 

<!-- Default -->
<label class="form-switch">
  <input type="checkbox" class="form-switch-input" checked>
  <span class="form-switch-label">Option 1</span>
</label>

<!-- Square -->
<label class="form-switch form-switch-square">
  <input type="checkbox" class="form-switch-input">
  <span class="form-switch-label">Option 2</span>
</label>

<!-- Outline -->
<label class="form-switch form-switch-outline">
  <input type="checkbox" class="form-switch-input">
  <span class="form-switch-label">Option 3</span>
</label>

Switch revealing a field (no JS)

.form-switch placed right before .grid-expand (as a sibling, not nested inside) reveals the content underneath once checked. Zero JavaScript — click the switch to see it. 

<label class="form-switch">
  <input type="checkbox" class="form-switch-input">
  <span class="form-switch-label">Send email notifications</span>
</label>

<!-- Sibling of the switch, NOT inside the same <label> -->
<div class="grid-expand">
  <div class="grid-expand-inner">
    <input type="email" class="input" placeholder="Email address">
  </div>
</div>
