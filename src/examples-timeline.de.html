Zeitleiste

Fertige Zeitleisten-Varianten — eine klassische Liste mit Icons und Nummerierung sowie eine fortgeschrittene, auf einem Grid basierende Variante mit Daten auf der linken Seite, ideal für ERP-/CRM-Systeme.

Zeitleiste (Timeline)

Eine Komponente zur Darstellung von Prozessen, der Firmengeschichte oder Projektetappen.

Variante mit Icons (.timeline-large)

  • A

    Grüne Umgebung

    Eine von Grünflächen umgebene Investition.

  • B

    Sicherheit

    Das Gelände ist eingezäunt und überwacht.

Automatische Nummerierung (.timeline-numbered)

  • Sie wählen eine Wohnung

    Sie durchstöbern das Angebot und wählen eine Einheit.

  • Sie unterschreiben den Vertrag

    Wir schließen die Formalitäten ab.

Die Variante .timeline-labeled basiert auf CSS Grid — ideal für ERP-/CRM-Systeme, bei denen links ein Datum oder eine Uhrzeit der Operation stehen muss.
