Menu Kontekstowe

Małe menu rozwijane, które przykleja się do przycisku, który je wywołał, wykorzystując CSS Anchor Positioning oraz Popover API.

Przyklejone Menu Kontekstowe (Anchor Popover)

Wykorzystuje najnowszy standard CSS Anchor Positioning oraz Popover API — samo pozycjonowanie i animacje to czysty CSS. 

<!-- 1. Przycisk wywołujący (Definiuje nazwę kotwicy) -->
<button popovertarget="menu1" style="anchor-name: --btn1;" class="btn btn-secondary">
  Opcje
</button>

<!-- 2. Menu Kontekstowe (Przykleja się do kotwicy) -->
<div id="menu1" popover class="popover-context" style="position-anchor: --btn1;">
  <ul class="popover-action-list">
    <li><button class="popover-action-btn">Edytuj</button></li>
    <li><button class="popover-action-btn text-danger">Usuń</button></li>
  </ul>
</div>
