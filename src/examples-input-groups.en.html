Input Groups

Ready-to-use combinations of fields with text, icons, and buttons, plus advanced inputs for date, color, and range.

Input Groups

Attach text, icons, or buttons directly to a text field — useful for search boxes and fields with units.

Price USD 
<!-- Search with magnifier -->
<div class="input-group">
  <input type="text" class="input" placeholder="Search...">
  <!-- FIX: bg-surface class removed -->
  <button class="btn text-muted">
    <!-- Magnifier icon -->
  </button>
</div>

<!-- Field with a unit -->
<div class="input-group">
  <span class="input-group-text">Price</span>
  <input type="number" class="input" placeholder="0.00">
  <span class="input-group-text">USD</span>
</div>

Advanced Inputs (Date, Color, Range)

Custom styles for date, color, and range inputs, ensuring visual consistency across browsers.

Click the square to change it 
<!-- Date Picker -->
<input type="date" class="input">

<!-- Color Picker -->
<input type="color" class="input-color" value="#0d6efd">

<!-- Range Slider -->
<input type="range" class="input-range" min="0" max="100" value="50">

Inline Form Row

.input-group-inline lays the label and field out side by side on one line (instead of stacked) and wraps safely on mobile without breaking the grid. 

<div class="input-group-inline">
  <label for="name">Full name</label>
  <input id="name" type="text" class="input">
</div>
