Dark Mode support

Built for dense B2B panels

Not another landing-page framework. We designed molique with dashboards, admin panels and data in mind — lots of it, dense and readable.

Zero JS wherever possible

Accordions, tabs, dropdowns, mega menus and modals run on plain HTML5 and CSS — the Radio Hack, <details> and Anchor Positioning instead of scripts.

A complete ecosystem

Forms, tables, charts, e-commerce and an admin panel — one coherent class system instead of stitching several libraries together.

Dark Mode built in

A single theme variable drives the entire color palette. Zero flicker (FOUC) when switching themes or on first page load.

Accessibility from the ground up

Enforced 44px touch targets on mobile, a visible :focus-visible and native form validation.

GPU performance

Animations exclusively on transform and opacity — zero costly reflow, even in dense tables.

Modular Sass

Import only what you need — from the base grid to the shop module, without any dead weight in the bundle.
