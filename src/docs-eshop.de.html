E-Commerce

Komponenten speziell für Onlineshops — die Produktkarte, die Fotogalerie, der Warenkorb und Auswahlkacheln im Checkout. Sie erfordern eine eigene Datei molique-style-shop.css, da sie nicht zum Kern des Frameworks gehören. Fertige Layouts finden Sie in den Beispielen.

1. Was wählen

Fünf unabhängige Komponenten — verwenden Sie so viele, wie Sie brauchen, keine setzt die anderen voraus.

Komponente Wann Worauf basiert es
.product-card Produktraster — Kategorie-Listing, Suchergebnisse. Flexbox
.product-gallery Einzelne Produktseite — Hauptfoto + klickbare Miniaturbilder zum Umschalten. Flexbox + JS (Austausch von src)
.cart-item Zeile im Warenkorb oder in der Bestellübersicht. Flexbox + JS (Mengenregler)
.selection-tile Auswahl der Versand- oder Zahlungsmethode im Checkout. Natives input[radio/checkbox], null JS
.star-rating / .product-swatches Produktbewertung und Auswahl der Farbvariante — meist innerhalb einer Karte. Reines CSS (SVG-Maske), null JS

2. Produktkarte

.product-price-block hat margin-top: auto — unabhängig von der Titellänge landen Preis und Button immer am unteren Rand der Karte, sodass Karten in derselben Rasterzeile auf gleicher Höhe enden. 

<article class="product-card">
  <a href="#" class="product-image-wrapper">
    <div class="product-badges">
      <span class="badge badge-danger">-30%</span>
    </div>
    <img src="produkt.jpg" alt="Produkt" style="height: 250px;">
  </a>
  <div class="product-content">
    <a href="#" class="product-title">Produktname</a>
    <div class="product-price-block">
      <span class="price-current">49,00 €</span>
      <span class="price-old">69,00 €</span>
    </div>
    <button class="btn-primary w-100">In den Warenkorb</button>
  </div>
</article>
Klasse Was sie macht
.product-card Hülle. height: 100% — im Raster gleicht sie sich an die höchste Karte in der Zeile an.
.product-image-wrapper Auf einem <a>. Das Bild darin hat keine Standardhöhe (height: auto) — ohne Inline-style="height:…" oder eine eigene Regel haben Karten im Raster unterschiedlich hohe Bilder.
.product-badges Absolut positioniert in der oberen linken Ecke. Darin gewöhnliche .badge-*.
.product-content Der Rest der Karte unter dem Bild. flex-grow: 1.
.product-title Textfarbe wechselt bei Hover zu --primary.
.product-price-block margin-top: auto — fixiert den Preisblock am unteren Rand der Karte. Ausrichtung baseline, sodass Preis und alter Preis trotz unterschiedlicher Schriftgrößen auf einer gemeinsamen Textlinie sitzen.
.price-current Aktueller Preis — groß, --primary.
.price-old Preis vor der Reduzierung — durchgestrichen, gedämpft.
Listenansicht statt Raster

Fügen Sie die Klasse .product-list-view zum übergeordneten Container hinzu (nicht zur Karte) — CSS baut alle .product-card-Elemente darin ohne Änderungen am HTML einer einzelnen Karte in ein horizontales Layout um. Unterhalb des Breakpoints sm kehrt das Layout automatisch zur vertikalen Anordnung zurück.

3. Produktgalerie

Ein großes Foto + eine Reihe klickbarer Miniaturbilder. Ein Klick auf ein Miniaturbild tauscht die src des Hauptfotos aus — ohne Neuladen, ohne Lightbox, ohne externe Karussell-Bibliothek.

So funktioniert es

Das Modul molique-shop.js (automatisch geladen bei .product-gallery) lauscht auf Klicks auf .gallery-thumb. Jedes liest das Attribut data-large aus seinem eigenen <img> und trägt diesen Wert als src des Hauptfotos ein — ohne dieses Attribut bewirkt der Klick nichts. Das Miniaturbild ist ein <button>, kein <a> und kein <div>, daher funktioniert die Tastaturbedienung (Tab, Enter), ohne dass etwas ergänzt werden muss. 

<div class="product-gallery">
  <div class="product-gallery-main">
    <img src="groß-1.jpg" alt="Produkt">
  </div>
  <div class="product-gallery-thumbs">
    <button type="button" class="gallery-thumb is-active">
      <img src="klein-1.jpg" data-large="groß-1.jpg" alt="">
    </button>
    <button type="button" class="gallery-thumb opacity-50">
      <img src="klein-2.jpg" data-large="groß-2.jpg" alt="">
    </button>
  </div>
</div>
Klasse Was sie macht
.product-gallery Hülle. Ohne Modifikator: Miniaturbilder in einer Reihe unter dem Foto — funktioniert bei jeder Breite, auch mobil.
.product-gallery-left Ab dem Breakpoint md: Miniaturbilder als Spalte LINKS vom Foto. Unterhalb von md — kehrt zum Standardlayout zurück (Reihe darunter). Die DOM-Reihenfolge ändert sich nicht, nur die visuelle (order).
.product-gallery-right Dasselbe wie -left, aber die Miniaturbild-Spalte bleibt rechts (DOM-Reihenfolge = visuelle Reihenfolge).
.product-gallery-main Quadratischer Container für das Hauptfoto (aspect-ratio: 1/1), das Bild füllt ihn über object-fit: cover.
.product-gallery-thumbs Die Leiste mit Miniaturbildern.
.gallery-thumb Ein einzelnes Miniaturbild (<button>, 64×64px). Erfordert ein <img data-large="…"> darin.
.is-active / .opacity-50 Zustand der Miniaturbilder — wird von JS nach dem Klick vergeben (aktives voll, restliche gedämpft). .opacity-50 ist eine fertige Utility-Klasse, keine eigene Komponentenklasse.

Standard (Miniaturbilder darunter)

.product-gallery-left (ab md)

<!-- Miniaturbilder links ab Breakpoint md -->
<div class="product-gallery product-gallery-left">
  …
</div>

4. Bewertungen und Farbvarianten

Zwei Mikro-Komponenten für das Innere einer Produktkarte. Beide rein visuell — null JavaScript. 

<!-- Bewertung 4,5 von 5 Sternen -->
<div class="star-rating" style="--rating: 4.5;"></div>

<!-- Farbauswahl -->
<div class="product-swatches">
  <div class="swatch is-active" style="background-color: #000;" title="Schwarz"></div>
  <div class="swatch" style="background-color: #ef4444;" title="Rot"></div>
</div>
Klasse / Variable Was sie macht
.star-rating Fünf Sterne, mit einer SVG-Maske aus einem linearen Verlauf ausgeschnitten. Der Wert wird AUSSCHLIESSLICH über die Variable --rating gesteuert (0–5, Nachkommastellen erlaubt) — es gibt kein Klassen-Äquivalent.
--star-color / --star-bg Farbe des gefüllten und leeren Teils der Sterne. Standard: --warning und --border-color.
--star-size Größe eines einzelnen Sterns (standardmäßig 16px) — skaliert die gesamte Breite der Komponente (--star-size × 5).
.product-swatches Reihe von Farbkreisen, flex-wrap.
.swatch Ein 24px-Kreis. Farbe über Inline- style="background-color:…" — es gibt kein Set fertiger Farbklassen (die Produktpalette ist beliebig, nicht auf die Farbpalette des Themes beschränkt).
.swatch.is-active Äußere --primary-Umrandung. Manuell im HTML oder per eigenem JS vergeben — das Shop-Modul verwaltet das nicht.

5. Warenkorb

Eine Warenkorbzeile mit eingebautem Mengenregler. Die +/--Buttons werden vom selben Modul bedient wie die Galerie — es beachtet die Attribute min und max des Feldes. 

<div class="cart-item">
  <img src="produkt.jpg" alt="Produkt" class="cart-item-img">

  <div class="cart-item-info">
    <a href="#" class="fw-bold text-decoration-none">Produktname</a>
  </div>

  <div class="cart-item-controls">
    <div class="qty-input">
      <button class="qty-btn">-</button>
      <input type="number" class="qty-val" value="1" min="1" max="99">
      <button class="qty-btn">+</button>
    </div>
    <div class="fw-black text-6">49,00 €</div>
    <button class="btn-action text-danger" aria-label="Entfernen">&times;</button>
  </div>
</div>
Klasse Was sie macht
.cart-item Die Zeile. Flexbox, flex-wrap — auf schmalen Bildschirmen brechen die Elemente um, statt sich zusammenzuquetschen.
.cart-item-img Miniaturbild 80×80px, object-fit: cover.
.cart-item-info flex-grow: 1 — nimmt den restlichen Platz ein und drängt Preis und Steuerelemente nach rechts.
.cart-item-controls Die Gruppe: Mengenregler + Preis + Entfernen.
.qty-input Hülle des Reglers. Höhe erzwungen auf --target-size-min (44px, B2B-Grundsatz) — unabhängig von der Größe der Buttons darin.
.qty-btn Der +/--Button. JS nimmt den ersten .qty-btn als Minus, den letzten als Plus — die DOM-Reihenfolge ist hier entscheidend, siehe Fallstrick unten.
.qty-val Das Zahlenfeld zwischen den Buttons. Muss type="number" mit dem Attribut min sein (optional auch max) — von dort liest JS die Grenzen. Der native Browser-Spinner ist ausgeblendet.

6. Auswahlkacheln

Für die Auswahl der Versand- oder Zahlungsmethode im Checkout. Ein verstecktes natives input[radio]/[checkbox] steuert das Erscheinungsbild des benachbarten .tile-content — null JavaScript, Auswahl und Formularvalidierung funktionieren nativ. 

<label class="selection-tile">
  <input type="radio" name="delivery" value="standard" checked>
  <div class="tile-content">
    <span class="fw-bold">Standardversand</span>
    <span class="text-primary fw-bold">12,99 €</span>
  </div>
</label>

<!-- Variante mit animiertem Rahmen bei Auswahl -->
<label class="selection-tile selection-tile-animated">
  <input type="radio" name="payment" value="blik">
  <div class="tile-content hover-border-trace">
    <span class="fw-bold">BLIK</span>
  </div>
</label>
Klasse Was sie macht
.selection-tile Auf einem <label>. Der Input darin ist visuell verborgen (nicht display: none, sodass er im Barrierefreiheitsbaum und in der Tastaturbedienung bleibt).
.tile-content Der sichtbare Inhalt der Kachel. Muss ein direktes Geschwister des Inputs sein — die CSS-Regel zielt darauf über :checked + .tile-content.
.selection-tile-animated Auf einem <label>, neben .selection-tile. Schaltet die sofortige Rahmenänderung aus und überlässt den Auswahleffekt der Klasse .hover-border-trace (oder -2), die zu .tile-content hinzugefügt wird.

7. Fallstricke

1 Miniaturbild ohne data-large

Das JS-Modul liest das große Foto ausschließlich aus dem Attribut data-large am <img> innerhalb des Miniaturbilds. Ohne dieses bewirkt ein Klick auf .gallery-thumb nichts — kein Fehler in der Konsole, die Prüfung if (newSrc) schlägt einfach nie an.

2 Zustand der Miniaturbilder wird nicht automatisch gesetzt

Das Modul bindet nur Klick-Listener ein — es führt keinen Startdurchlauf über die Fotos aus. Wenn Sie das erste Miniaturbild nicht manuell im HTML als .is-active und die übrigen als .opacity-50 markieren, sehen alle Miniaturbilder bis zum ersten Klick identisch aus.

3 Mehr als zwei .qty-btn in .qty-input

JS nimmt :first-child als Minus und :last-child als Plus. Ein zusätzlicher Button (z. B. „Jetzt kaufen" im selben Container) bringt dieses Paar durcheinander — das dritte Element wird zum neuen „Plus", und der eigentliche Plus-Button hört auf zu funktionieren. Halten Sie in .qty-input genau zwei .qty-btn und einen .qty-val.

4 .product-list-view am falschen Element

Die Klasse muss auf den Container treffen, der die Karten umgibt (z. B. .grid-auto), nicht auf eine einzelne .product-card. Die SCSS-Selektoren sind vom Typ .product-list-view .product-card — an der Karte selbst ändert sich nichts.
