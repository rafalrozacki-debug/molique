Podstawy Formularzy

Gotowe do skopiowania warianty podstawowych pól tekstowych molique — pływające etykiety, natywna walidacja, rozmiary oraz samorozwijająca się textarea.

Pływające Etykiety (Floating Labels)

Etykieta znajduje się wewnątrz pola i płynnie wędruje do góry po kliknięciu lub rozpoczęciu pisania. 

<div class="form-floating">
  <!-- Atrybut placeholder=" " jest wymagany dla magii CSS! -->
  <input type="text" class="input" id="imie" placeholder=" ">
  <label for="imie">Imię i nazwisko</label>
</div>

Natywna Walidacja (Zero JS)

Wykorzystuje pseudoklasę :user-invalid — komunikat błędu pojawia się dopiero, gdy użytkownik opuści niepoprawnie wypełnione pole.

Proszę podać poprawny adres e-mail. 
<div class="form-floating">
  <input type="email" class="input" id="email" placeholder=" " required>
  <label for="email">Służbowy e-mail</label>

  <!-- Komunikat błędu (CSS sam go pokaże dzięki :user-invalid) -->
  <div class="feedback-invalid">Błędny adres e-mail.</div>
</div>

Warianty Wielkości (sm / lg)

Każdy element z klasą .input — input, select i textarea — obsługuje te same modyfikatory wielkości. 

<input type="text" class="input input-sm" placeholder="Kompaktowy">
<input type="text" class="input" placeholder="Domyślny">
<input type="text" class="input input-lg" placeholder="Duży">

<select class="input input-sm">...</select>

Textarea „Jedna Linijka" (Auto-Expand)

Pole zajmuje wysokość jednej linijki, a po kliknięciu lub wpisaniu treści rozwija się do kilku wierszy — bez JavaScriptu. 

<textarea
  class="input textarea-expandable"
  rows="1"
  placeholder="Kliknij, aby rozwinąć…"
  style="--textarea-rows-expanded: 8;"
></textarea>
