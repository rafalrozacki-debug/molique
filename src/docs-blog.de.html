Blog & Artikel

Vier Komponenten für Nachrichtenportale und Unternehmensblogs — vom Artikelraster bis zum Autorenbereich. Sie benötigen die separate Datei molique-style-blog.css. Vollständige Layouts finden Sie in den Beispielen: Beiträge, Sidebar, Autor.

1. Was wählen

Vier unabhängige Komponenten — keine benötigt die anderen.

Komponente Wann Basiert auf
.post-card Artikelraster — Blog-Startseite, Kategorie. Flexbox
.blog-post Klassische Liste von Beiträgen untereinander — Archiv, Suchergebnisse. Flexbox
.simple-post-list Widget „Neueste Beiträge" in der Sidebar oder im Footer. Flexbox
.author-box Autoren-Block — meist ganz unten im Artikelinhalt. Flexbox

2. Beitragskarte (Post Card)

Eine Karte für ein Raster, mit einem über dem Bild schwebenden Datum und einem Meta-Bereich (Autor, Kategorie) über dem Titel.

Klasse Was sie tut
.post-card Die Hülle. height: 100% — richtet sich im Raster an der höchsten Karte der Reihe aus.
.post-image-wrapper Auf einem <a>. position: relative — der Anker für .post-date-badge. Das Bild hat eine feste Höhe von 240px, unabhängig vom Seitenverhältnis des Originals.
.post-date-badge Absolut positioniert in der oberen linken Ecke. Muss innerhalb von .post-image-wrapper liegen — siehe Fallstrick unten.
.post-content Der Rest der Karte unter dem Bild. flex-grow: 1.
.post-meta Eine Zeile mit Metadaten (Autor, Kategorie…) über dem Titel. Nicht zu verwechseln mit .post-meta-date aus dem Sidebar-Widget — siehe Fallstrick unten.
.post-title Der Titel. Wechselt beim Hover zu --primary.

3. Klassischer Beitrag (List View)

Das traditionelle Blog-Archiv-Layout — ein großes, kalenderartiges Datum links vom Bild. Unterhalb des sm-Breakpoints springt das Datum über das Bild, das Layout wird vertikal. 

<article class="blog-post">
  <div class="post-date">
    <span class="month">Mai</span>
    <span class="day">24</span>
  </div>

  <div class="flex-grow-1">
    <a href="#" class="blog-post-image"><img src="foto.jpg" alt=""></a>
    <div class="post-meta">...</div>
    <a href="#" class="post-title">Beitragstitel</a>
    <p>Anrisstext...</p>
  </div>
</article>
Klasse Was sie tut
.blog-post Eine Zeile. Trennlinie darunter, der letzte Beitrag in der Liste hat keine (:last-child).
.post-date Eine 55px breite Kalenderspalte. Enthält .month und .day — dieselben Namen wie in .post-date-badge, aber mit anderem Aussehen: Hier ist der Monat ein oberer Balken in --primary, der Tag eine weiße Karte darunter. Siehe Fallstrick unten.
.blog-post-image Das Bild über dem Titel, ohne schwebendes Datum. Freie Höhe (height: auto).

4. Kompakte Beitragsliste (Sidebar Widget)

Eine kompakte Liste mit Miniaturbildern — „Neueste Beiträge" in der Sidebar oder im Footer. 

<ul class="simple-post-list">
  <li>
    <img src="thumb.jpg" class="post-image" alt="Miniaturansicht">
    <div class="post-info">
      <a href="#">Artikeltitel</a>
      <span class="post-meta-date">24. Mai 2026</span>
    </div>
  </li>
</ul>
Klasse / Variable Was sie tut
.simple-post-list Auf einem <ul>. Setzt die Listendarstellung zurück, gepunkteter Trenner zwischen den Einträgen.
.post-image Die Miniaturansicht. AUSSCHLIESSLICH innerhalb von .simple-post-list gestylt — außerhalb davon ist es ein gewöhnliches <img> ohne jegliche Regeln.
--post-thumb-size Größe der Miniaturansicht (Standard 60px). Setzen Sie style="--post-thumb-size: 48px;" auf .simple-post-list oder ein einzelnes <li>.
.post-info Die Spalte für Titel + Datum, nur innerhalb von .simple-post-list.
.post-meta-date Ein kleines Datum unter dem Titel. Nicht zu verwechseln mit .post-meta aus Karte und klassischem Beitrag — eine andere Klasse, ein anderes Aussehen.

6. Fallstricke

1 .day / .month sehen in jedem Kontext anders aus

Dieselben Klassennamen haben in Sass ZWEI verschiedene Stile, je nach Elternelement: innerhalb von .post-date-badge (schwebendes Datum auf einem Foto) ist der Tag eine große Zahl über einem kleinen Monat; innerhalb von .post-date (klassische Liste) ist der Monat ein oberer Balken in der Farbe --primary, der Tag eine weiße Karte darunter. Außerhalb beider Kontexte verwendet — haben sie keinerlei Stil.

2 .post-date-badge außerhalb von .post-image-wrapper

Das Datum ist position: absolute positioniert und verankert sich am nächsten Vorfahren mit position: relative — dieser Vorfahre ist .post-image-wrapper. Anderswo platziert, klebt es an einem weiter entfernten Vorfahren oder an der gesamten Seite statt an der Ecke des Bildes.

3 .post-meta und .post-meta-date sind nicht dieselbe Klasse

Täuschend ähnliche Namen, kein gemeinsamer Code. .post-meta (Karte, klassischer Beitrag) ist eine Zeile mit Links und Icons. .post-meta-date (Sidebar-Widget) ist ein einzelner, kleiner Datumstext. Das eine gegen das andere auszutauschen ergibt visuell kein 1:1-Ergebnis.
