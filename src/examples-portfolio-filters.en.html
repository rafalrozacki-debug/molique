Portfolio Filters (Nav Filters)

A menu that filters elements on the page (e.g. a gallery or portfolio). Requires the bundled JS script to hide/show elements.

Website 2 
<!-- Filter menu -->
<ul class="nav-filters">
  <li><button class="is-active" data-filter="all">All</button></li>
  <li><button data-filter="www">Websites</button></li>
</ul>

<!-- Items to filter (directly below the menu) -->
<div class="grid-auto">
  <div class="filter-item" data-category="www">Project 1</div>
  <div class="filter-item" data-category="ads">Project 2</div>
</div>
