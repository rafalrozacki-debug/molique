Sortable List

Reorder items via two equal, parallel paths: dragging a handle (Pointer Events - works with mouse, touch, and pen) and up/down buttons, the only path for keyboard and screen-reader users.

Navigation menu order

A common admin scenario: a client sets their own site menu order. The data-sortable class on the container is all it takes - js/modules/molique-sortable.js loads itself.

Zero config, zero backend

After every change (drag or button) the container emits CustomEvent('sortable:update', { detail: { order, items } }) - persisting the new order is your app's job. Full class/attribute/event reference in the Admin docs.
