Sortowalna lista

Zmiana kolejności elementów dwiema równorzędnymi drogami: przeciąganiem uchwytu (Pointer Events - działa myszką, dotykiem i piórem) oraz przyciskami góra/dół, jedyną ścieżką dla klawiatury i czytników ekranu.

Kolejność linków w menu nawigacji

Zero configu, zero backendu

Po każdej zmianie (przeciąganiem albo przyciskiem) kontener emituje CustomEvent('sortable:update', { detail: { order, items } }) - zapis nowej kolejności do bazy to zadanie Twojej aplikacji. Pełna referencja klas, atrybutów i zdarzenia w dokumentacji Admina.
