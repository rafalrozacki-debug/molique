Searchable Select & Switche

Zaawansowane kontrolki formularzy niezbędne w systemach B2B. Zbudowane hybrydowo: wykorzystują natywne tagi HTML5 do zarządzania stanem, wspierane lekkim JS do filtrowania.

1. Searchable Select (Combobox)

Zastępuje klasyczny tag <select>. Otwieranie i zamykanie działa natywnie dzięki Popover API — menu renderuje się w top layer, więc nie jest przycinane nawet wewnątrz modala.

Architektura i integracja:
  • Zero JS dla UI: Otwieranie opiera się na natywnym Popover API (popovertarget na przycisku + atrybut popover na menu). Zamykanie klawiszem Esc i kliknięciem poza menu obsługuje przeglądarka (light dismiss).
  • Top layer: Menu renderuje się w top layer przeglądarki, więc nie jest przycinane przez przewijane kontenery — działa poprawnie także wewnątrz modala <dialog>.
  • Unikalne ID: Każda instancja wymaga unikalnego id na menu, wskazanego w atrybucie popovertarget przycisku.
  • Backend: Wybrana wartość jest automatycznie wstawiana do ukrytego pola <input type="hidden" class="select-search-hidden">. Dzięki temu formularz wysyła dane do PHP dokładnie tak samo, jak przy użyciu standardowego selecta.
  • Wymagania: Komponent wymaga załadowania pliku molique-script.js do obsługi wyboru opcji (wpis do ukrytego pola) oraz filtrowania podczas wpisywania tekstu.
  • Wyszukiwarka jest opcjonalna: pomiń .select-search-input, a komponent działa jak klasyczny select — sama lista opcji (przykład niżej).

<div class="select-search">
  <button type="button" class="input select-search-trigger" popovertarget="klient-select">
    <span>Wybierz z listy...</span>
  </button>

  <!-- [popover] = top layer: menu nie jest przycinane nawet w modalu -->
  <div class="select-search-menu" popover id="klient-select">
    <input type="text" class="input select-search-input" placeholder="Szukaj...">
    <div class="select-search-list">
      <div class="select-search-option" data-value="1">Opcja 1</div>
      <div class="select-search-option" data-value="2">Opcja 2</div>
    </div>
  </div>

  <!-- Ukryte pole dla backendu -->
  <input type="hidden" name="klient_id" class="select-search-hidden">
</div>

Wariant bez wyszukiwarki (zwykły select)

Pole .select-search-input jest opcjonalne — po jego pominięciu komponent działa jak klasyczny <select>: sama lista opcji, nadal w top layer i bez przycinania w modalach. Aktywną opcję oznacz klasą .is-selected i ustaw value ukrytego pola.

  <button type="button" class="input select-search-trigger" popovertarget="status-select">
    <span>Planowanie</span>
  </button>

  <!-- Bez .select-search-input = zwykły select -->
  <div class="select-search-menu" popover id="status-select">
    <div class="select-search-list">
      <div class="select-search-option is-selected" data-value="planowanie">Planowanie</div>
      <div class="select-search-option" data-value="oczekuje">Oczekuje</div>
      <div class="select-search-option" data-value="w-trakcie">W trakcie</div>
    </div>
  </div>

  <input type="hidden" name="status" class="select-search-hidden" value="planowanie">
</div>

2. Premium Multi Select

Zaawansowany komponent do wyboru wielu opcji, wzorowany na nowoczesnych interfejsach SaaS. Posiada wbudowaną wyszukiwarkę, podział na kategorie i interaktywne karty opcji.

Zasada działania (Zero JS dla UI):
  • Natywny Dropdown: Otwieranie opiera się na Popover API (popovertarget + popover), a menu renderuje się w top layer — nie jest przycinane przez przewijane kontenery ani modale. Esc i klik poza menu zamykają je natywnie.
  • Magia CSS: Karty opcji (.custom-select-option) automatycznie zmieniają kolor i obramowanie, gdy ukryty w nich checkbox zostanie zaznaczony, dzięki selektorowi :has(input:checked).
  • Kategorie: Użyj <div class="custom-select-category">, aby pogrupować opcje w logiczne sekcje.

Inne
<div class="custom-select">
  <button type="button" class="custom-select-trigger" popovertarget="skills-select">
    <!-- Tagi i strzałka -->
  </button>

  <!-- [popover] = top layer: menu nie jest przycinane nawet w modalu -->
  <div class="custom-select-dropdown" popover id="skills-select">
    <!-- Wyszukiwarka -->
    <div class="custom-select-search">
      <input type="text" class="input" placeholder="Szukaj...">
    </div>
    
    <div class="custom-select-list">
      <div class="custom-select-category">Kategoria</div>
      
      <!-- Karta opcji -->
      <label class="custom-select-option">
        <div class="flex-1">
          <div class="fw-bold">Opcja 1</div>
        </div>
        <input type="checkbox" class="form-check-input">
      </label>
    </div>
  </div>
</div>

2. Przełączniki (Switche)

Zbudowane na bazie natywnego <input type="checkbox">. Posiadają wymuszone 44px wysokości dla dostępności B2B.

Dostępne warianty wizualne:
  • .form-switch — Domyślny wariant w stylu iOS (zaokrąglony, pełne tło).
  • .form-switch-square — Wariant kwadratowy, idealny do surowych, technicznych interfejsów B2B.
  • .form-switch-outline — Wariant konturowy, oparty na obramowaniu. Przezroczyste tło nadaje mu minimalistyczny charakter.

Domyślny (iOS Style)

Kwadratowy (.form-switch-square)

Konturowy (.form-switch-outline) 

<!-- Domyślny -->
<label class="form-switch">
  <input type="checkbox" class="form-switch-input" checked>
  <span class="form-switch-label">Opcja 1</span>
</label>

<!-- Kwadratowy -->
<label class="form-switch form-switch-square">
  <input type="checkbox" class="form-switch-input">
  <span class="form-switch-label">Opcja 2</span>
</label>

<!-- Konturowy -->
<label class="form-switch form-switch-outline">
  <input type="checkbox" class="form-switch-input">
  <span class="form-switch-label">Opcja 3</span>
</label>
