Statuses, Errors, and Layout

Microinteractions that inform the user about the application's state, plus smoothly expanding containers.

Status Ping (Pulsing dot)

System operational (Live)

Micro Shake (Error)

Grid Expand (Smooth expand without max-height)

This text expands perfectly smoothly thanks to animating grid-template-rows: 0fr to 1fr. No more hacking max-height: 1000px! 
<!-- Pulsing dot -->
<span class="status-dot status-done status-ping">Live</span>

<!-- Shake (add the .shake class) -->
<button class="btn shake">Error</button>

<!-- Smooth expand (Grid Expand) -->
<div class="grid-expand is-open">
  <div class="grid-expand-inner">
    Content that expands smoothly...
  </div>
</div>

Interactive Status Icon (Checkbox)

A single HTML element that smoothly transforms from an "Add" state to a "Success" state, working as a fully functional checkbox.

Check me!

<!-- Fully functional form checkbox -->
<label class="status-checkbox">
  <input type="checkbox" name="field_name" value="1">
  <span class="status-icon-toggle"></span>
</label>

Static Status Icons

The .status-icon base underlying the checkbox above — useful when you just need the state itself (no interactivity), e.g. as a marker in a step list. 

<!-- "Add" state -->
<span class="status-icon status-icon-add"></span>

<!-- "Success" state -->
<span class="status-icon status-icon-success"></span>
