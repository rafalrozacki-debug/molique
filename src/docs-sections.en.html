Sections, Hero & Timeline

The building blocks of a landing page: a header with a photo, a text overlay, parallax, and timelines. Ready-made blocks: hero examples and timeline.

1. A header with a photo

.page-header is a section with a background image — you supply the image itself via background-image, since it comes from content, not the framework. The class only handles the framing: cover, centered, no repeat. 

<header class="page-header has-overlay p-5"
        style="background-image: url(photo.jpg)">
  <div class="overlay overlay-dark overlay-60"></div>
  <div class="container position-relative z-10">
    <h1 class="text-white">Page title</h1>
  </div>
</header>
Class What it does
.page-header Frames the background image: cover, centered, no repeat.
.has-overlay On the parent. Sets up the context for an overlay — without it, the overlay has nothing to anchor to.

2. Overlays

A photo is rarely evenly dark, so white text may be readable in one corner and not in another. An overlay is a color layer between the photo and the content. Splitting it into color and opacity lets you adjust one without touching the other, and .overlay already has a useful default: 50% darkening.

overlay-primary + overlay-60
Class Group What it does
.overlay Base A layer filling the parent. By itself already gives 50% darkening — the color and opacity classes only adjust it. Requires .has-overlay above.
.overlay-dark Color Darkening. Also: .overlay-light, .overlay-primary. Pure black is .bg-overlay.
.bg-overlay Color A black overlay, with no theme tint.
.overlay-10 – .overlay-90 Opacity In steps of ten percent. Without any of them, the default 50% applies.

Content must be above the overlay

The overlay sits on top of the photo, but also on top of everything else inside. Content therefore needs to be lifted: .position-relative plus .z-10. Skipping this gives "the text dimmed along with the photo" — the most common hero mistake.

3. Hero with a cutout

A layout where content bites into the corner of a photo — the photo looks as if it has a corner cut out. The effect is desktop-only: on a narrow screen there's nowhere to cut, so the blocks stack one below the other. 

<div class="hero-with-cutout">
  <img src="photo.jpg" alt="">
  <div class="cutout-wrapper cutout-md-bl p-5">
    <h2>Content in the cutout</h2>
  </div>
</div>
Class What it does
.hero-with-cutout The wrapper: the photo plus the content block.
.cutout-wrapper The block biting into the photo. Its background comes from --cutout-bg; set it to the section's color, or the cutout won't blend with the page background.
.cutout-md-bl Which corner of the photo gets cut: bl — bottom-left. Also: .cutout-md-br, .cutout-md-tl, .cutout-md-tr. The md prefix says outright that the effect starts at tablet width.

The corner radius

The size of the cutout is set by --cutout-radius (defaults to 32px). The same variable drives the cutout illusion in the admin panel's header — see Admin Panel.

4. Parallax and stacked sections

Parallax

A background that moves slower than the content. The motion is driven by scroll position, not a scroll event in JS — so the animation is computed off the main thread and doesn't stutter on a heavy page. 

<div class="parallax-container">
  <img class="parallax-bg" src="photo.jpg" alt="">
  <div class="parallax-content">
    <h2>Content on top</h2>
  </div>
</div>

Stacked sections

Successive sections slide over the previous ones like a deck of cards. It rests on position: sticky, so it works without a script. 

<div class="stacking-container">
  <section class="section-stacked">First</section>
  <section class="section-stacked">Second slides over the first</section>
</div>
Class What it does
.parallax-container The wrapper; clips the overflowing background.
.parallax-bg The background image. Deliberately taller than the container — it needs slack to shift.
.parallax-content The content above the background.
.stacking-container The wrapper for stacked sections.
.stacking-container-snap A snapping variant: scrolling stops at a full section. Requires its own height and scrolling.
.section-stacked A single section in the deck.
.bg-gradient-corners A subtle glow in the corners of a section — a background with no photo (always dark).
.bg-gradient-corners-light Same glow, on a light background that flips with the theme.

5. Timeline

For a company's history, project milestones, a changelog. Two layouts: a basic one with content on one side of the axis, and .timeline-labeled with dates in a separate column. 

<ul class="timeline timeline-labeled">
  <li class="timeline-item">
    <div class="timeline-label">2026</div>
    <div class="timeline-separator">
      <div class="timeline-node node-success"></div>
      <div class="timeline-line"></div>
    </div>
    <div class="timeline-content">Event description</div>
  </li>
</ul>
Class What it does
.timeline The timeline's wrapper.
.timeline-item A single event.
.timeline-content The event's content.
.timeline-badge The marker on the axis in the basic layout.
.timeline-large A variant with larger spacing.
.timeline-numbered Numbers the events automatically.
.timeline-labeled A layout with dates in a separate column on the left. Requires three blocks per event — see the code above.
.timeline-label The date column. Width: --timeline-label-width.
.timeline-separator The middle column: the dot and the line.
.timeline-node The dot. Colored via .node-primary, .node-success, .node-danger, or the --timeline-dot-color variable.
.timeline-line The vertical line connecting events.

Timeline variables

--timeline-spacing (spacing between events), --timeline-dot-size, --timeline-dot-color, --timeline-line-color, --timeline-label-width. The .node-* classes are a shortcut for the most common dot colors; for any other color, use the variable.

6. Stepper

A timeline shows the past; a stepper shows progress through a process: an order, an onboarding flow, a multi-step form. Hence the two states a timeline doesn't have. 

<div class="stepper stepper-numbered">
  <div class="step is-completed">Cart</div>
  <div class="step is-active">Delivery</div>
  <div class="step">Payment</div>
</div>
Class What it does
.stepper The wrapper for the steps.
.stepper-numbered Numbers the steps instead of drawing dots.
.step A single step.
.step-line The connector between steps.
.is-active The current step. Should be exactly one.
.is-completed A finished step — all of them before the current one.

7. Pitfalls

1 An overlay with no .has-overlay on the parent

The overlay is absolutely positioned, so it looks for the nearest ancestor with its own context. Without .has-overlay it will find something higher up — in the worst case, the whole page — and spill outside the section. This class also gives overflow: hidden, so the container's rounded corners clip the overlay. 

<!-- WRONG - the overlay escapes the section -->
<div class="page-header">
  <div class="overlay"></div>
</div>

<!-- RIGHT -->
<div class="page-header has-overlay">
  <div class="overlay"></div>
</div>
2 Content under the overlay instead of above it

The overlay covers everything inside the parent, including text and buttons. Symptom: the text looks dimmed along with the photo, and a button doesn't respond to clicks because the layer sits above it. Lift the content with .position-relative and .z-10.

3 Checking the cutout on a narrow window

.cutout-md-* only kicks in from tablet width — on a phone the blocks stack one below the other, since there's nothing to cut in a narrow column. This is intentional, not a bug. The md prefix in the name says so outright.

A second thing: .cutout-wrapper takes its background from --cutout-bg. If the section has a background other than the default, set this variable — otherwise the cutout shows up as a rectangle in a different color.

4 A timeline used for a process

.timeline has no states — every event looks the same, since it describes the past. To show where the user currently stands, use .stepper with its .is-active and .is-completed states. Marking a "current" event on a timeline would require writing your own CSS.
