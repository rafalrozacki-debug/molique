Paket verkleinern

Der Kern ist ~278 KB groß, aber kaum jemand nutzt alles davon. Es gibt zwei Wege, das zu reduzieren — beginnen Sie mit dem ersten, denn er birgt überhaupt kein Risiko.

1. Module auswählen

Risikofrei

Sie laden keinen Shop, Blog oder kein Admin-Panel? Binden Sie diese Dateien einfach nicht ein. Jedes Modul ist ein eigenes css/molique-style-*.css.

  • 66 Module zur Auswahl, Abhängigkeiten automatisch ausgewählt
  • Größe live berechnet, null Konfiguration
Konfigurator öffnen ➔

2. PurgeCSS

Schneidet ungenutzte Klassen aus dem heraus, was übrigbleibt. Effektiv (277 KB → 68 KB), erfordert aber eine Safelist — manche Klassen werden von JS zur Laufzeit hinzugefügt, und PurgeCSS sieht sie nicht.

Schnellstart

Entpacken, css/ und js/ in Ihr Projekt kopieren und zwei Dateien einbinden. Vollständiges Beispiel: starter.html im Paket. 

<!-- im <head> -->
<link rel="stylesheet" href="css/molique-style.min.css" />

<!-- am Ende von <body> (Modul-Autoloader) -->
<script defer src="js/molique-script.js"></script>
Motiv: Farben, Typografie und andere Variablen wählen Sie visuell im Theme Editor, und das Ergebnis fügen Sie als :root-Block ein. Schriftarten: Wenn Sie beim Herunterladen die Schriftarten-Option angehakt haben, kopieren Sie einfach den Ordner fonts/ neben css/ - die @font-face-Regeln in molique-style.css zeigen bereits darauf. Ohne diese Option laden Sie Inter + Poppins selbst von fonts.google.com herunter.
