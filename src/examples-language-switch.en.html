Language Switch

A pill-shaped language dropdown — the trigger opens the menu as a top-layer popover (the same pattern as the Dropdown Popover), zero JavaScript. Flags are tiny SVG files from img/flags/ — emoji flags don't render on Windows.

Language Switcher

The trigger shows the flag and code of the active language. The list opens from the right edge (.dropdown-menu-end), so it works safely as the last item in the navbar. The active item shows a checkmark. The img/flags/ folder contains only the flags of the languages offered in the project (individual SVG files at ~200 B each, inserted via <img>) — each loads once and is cached for the whole site.
