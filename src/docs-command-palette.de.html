Befehlspalette

Ein Suchfeld mit Ergebnisliste, geöffnet über einen Button oder ein Kürzel. Zu einer Seite springen, eine Aktion ausführen, einen Datensatz finden, ohne sich durch Menüs zu klicken. Sie steht auf einem nativen <dialog>, die Ebene über der Seite, die Fokusfalle und Esc kommen also vom Browser.

1. Ausprobieren

Öffne sie mit dem Button oder Strg + K. Tippe „Auftragnehmer”, und ein Tag findet die Seite. Tippe „ko”, und kurz darauf kommen Ergebnisse, die eine Serverantwort spielen.

2. Markup

Einträge im HTML werden direkt gefiltert: ohne Diakritika, nach sichtbarem Text und nach den Wortstämmen in data-tags. Ein Eintrag ist ein Link oder ein Button, beide sehen gleich aus. 

<button data-command-palette-open="#palette">Suchen</button>

<dialog class="command-palette" id="palette" aria-label="Suchen"
        data-command-palette-hotkey="k">
  <div class="command-palette-header">
    <input class="command-palette-input" placeholder="Suchen...">
  </div>
  <div class="command-palette-list">
    <div class="command-palette-group">
      <div class="command-palette-group-label">Seiten</div>
      <a class="command-palette-item" href="/clients" data-tags="auftrag firm">Kunden</a>
      <button class="command-palette-item" type="button" data-value="new">Neuer Auftrag</button>
    </div>
  </div>
</dialog>

3. Klassen

Klasse Was sie macht
.command-palette An einem <dialog>. Breite: --command-palette-width (640px). Füllt auf dem Handy den ganzen Bildschirm.
.command-palette-header Die Zeile mit Icon und Feld.
.command-palette-input Das Feld. Die Rolle combobox und die Verbindung zur Liste setzt das Skript.
.command-palette-list Die scrollbare Ergebnisliste.
.command-palette-group Eine Gruppe von Einträgen. Verschwindet, wenn nichts darin passt.
.command-palette-group-label Die Gruppenüberschrift.
.command-palette-item Ein Eintrag: <a> oder <button>. data-tags enthält Suchstämme, data-value landet im Event.
.command-palette-item-label Der Haupttext eines Eintrags, mit Auslassungspunkten gekürzt.
.command-palette-item-meta Ein Zusatz rechts: Steuernummer, Abteilung, Kürzel.
.command-palette-footer Eine optionale Leiste mit Tastenhinweisen. Verschwindet auf Touchscreens.
.command-palette-close Der Schließen-Button. Erstellt das Skript, sichtbar nur auf Touchscreens und bis 768 px, wo es weder Esc noch einen Hintergrund zum Antippen gibt.
.command-palette-empty Die Meldung für den leeren Zustand, das Warten und Fehler. Erstellt das Skript.
.command-palette-remote Der Container für Serverergebnisse. Erstellt das Skript.

4. Ergebnisse vom Server

molique hat kein Backend, die Anfrage sendet also dein Code. Ergebnisse kommen über ein Event, nicht über eine Funktion: Das Modul lädt asynchron, und der Listener kann jederzeit dazukommen, auch bevor das Modul da ist. 

// ein Ergebnis: { label, href?, meta?, group?, value? }
document.addEventListener('command:search', (e) => {
  const { query, signal, respond } = e.detail;
  respond(
    fetch('/api/search?q=' + encodeURIComponent(query), { signal })
      .then((response) => response.json())
  );
});
  • respond() nimmt ein Array oder ein Promise. signal bricht die Anfrage ab, wenn jemand weitertippt, und eine verspätete Antwort auf eine ältere Anfrage wird ignoriert.
  • Alles landet als Text auf der Seite, ein Datensatz namens <img onerror=...> bleibt also ein Name. Eine andere Adresse als http(s) wird verworfen, und der Eintrag wird zum Button ohne Link.
  • Berechtigungen prüft der Server. Die Palette zeigt, was sie bekommt.

Die Wahl eines Eintrags löst command:select aus. preventDefault() verhindert, dass dem Link gefolgt wird: 

document.addEventListener('command:select', (e) => {
  if (e.detail.value === 'new') {
    e.preventDefault();
    openOrderForm();
  }
});

5. Attribute und API

Attribut Was sie macht
data-command-palette-open="#id" An jedem Button: öffnet diese Palette.
data-command-palette-hotkey="k" Am Dialog: Strg/Cmd + Taste öffnet und schließt. Optional, denn ein Framework sollte keine Tasten belegen. Wirkt nicht in einem contenteditable-Editor und nicht über einem anderen offenen Dialog.
data-command-palette-min="2" Ab wie vielen Zeichen der Server gefragt wird.
data-command-palette-debounce="200" Wie viele Millisekunden nach dem letzten Zeichen gewartet wird.
data-command-palette-empty="..." Eigener Text für den leeren Zustand. Die Vorgabe folgt dem lang des Dokuments (PL/EN/DE).
MoliqueCommandPalette.open(el) Öffnet aus dem Code. Dazu .close(el). Das Modul lädt asynchron, rufe das also nach einem Klick auf, nicht beim Seitenstart.

6. Tastatur

Taste Was sie macht
↑ ↓ Bewegung durch die Ergebnisse, mit Umlauf.
Pos1, Ende Erstes und letztes Ergebnis, solange das Feld leer ist. Mit Text im Feld gehören sie dem Cursor.
Enter Wählt den hervorgehobenen Eintrag.
Esc Schließt und gibt den Fokus an das zurück, was die Palette geöffnet hat.

Der Fokus bleibt im Feld, Tippen funktioniert also jederzeit, und aria-activedescendant sagt dem Screenreader, welcher Eintrag hervorgehoben ist. Dieselbe Bedienung gilt in Searchable Select und Multi Select.

7. Fallstricke

Tags sind Wortstämme, keine Wörter.

Ein Stamm muss die Beugung abdecken: auftrag findet „Auftrags” und „Aufträgen”.

Rufe die API nicht beim Seitenstart auf.

MoliqueCommandPalette gibt es dann vielleicht noch nicht. Nutze für Ergebnisse das Event und zum Öffnen data-command-palette-open.

Eine neue Anfrage springt immer an den Anfang der Liste.

Enter soll den besten Treffer meinen, nicht eine Position aus der vorherigen Suche. Später eintreffende Ergebnisse stören nicht, was die Pfeiltasten schon erreicht haben.
