Modals

Native dialog windows built on the <dialog> tag — the browser handles the backdrop, focus trap, and closing with the ESC key on its own.

Native Modals (<dialog>)

Enter/exit animations are handled by CSS @starting-style, no JS libraries required. 

<!-- Opening button -->
<button onclick="document.getElementById('demoModal').showModal()">Open</button>

<!-- Modal Structure -->
<dialog id="demoModal" class="modal-dialog">
  <div class="card">
    <div class="card-header">Title</div>
    <div class="card-body">Modal content...</div>
    <div class="card-footer">
      <!-- Native closing, no JS! -->
      <form method="dialog">
        <button class="btn btn-secondary">Close</button>
      </form>
    </div>
  </div>
</dialog>

Confirmation Modal & Small Modal

.modal-confirm is a centered layout with no header (icon + question + two equal buttons) for "are you sure?" confirmations. .modal-sm is just a width modifier (360px) for short messages. 

<dialog class="modal-dialog modal-confirm">
  <div class="card">
    <div class="card-body">
      <div class="modal-confirm-icon">⚠️</div>
      <h5 class="fw-bold mb-2">Delete this record?</h5>
      <p class="text-muted m-0">This action cannot be undone.</p>
    </div>
    <div class="card-footer">
      <form method="dialog"><button class="btn btn-secondary">Cancel</button></form>
      <form method="dialog"><button class="btn btn-danger">Delete</button></form>
    </div>
  </div>
</dialog>

<!-- Just the width modifier -->
<dialog class="modal-dialog modal-sm">...</dialog>
