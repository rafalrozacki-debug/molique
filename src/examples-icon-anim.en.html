Animated Icons

Phosphor icons that react to the pointer, a tap and scrolling. What moves is what the icon shows: the lid of the bin, the shackle of the padlock, the hands of the clock. An opt-in module, class reference on Animated Phosphor Icons.

Framework: molique

The author of molique is Rafał Różacki.

Icons: Phosphor Icons

The icons were designed by Helena Zhang and Tobias Fried. The Phosphor Icons family is released under the MIT License (© Phosphor Icons). The animations are molique’s own. This module is not a Phosphor project and is not endorsed by its team.

In the interface

The trigger sits on the button or the link, so the icon moves whenever the pointer is anywhere on the element. .icon-anim-tap next to .icon-anim-hover gives the same on a phone.

<!-- Requires: molique-style-icon-anim.css -->
<button class="btn-primary icon-anim-hover icon-anim-tap">
  <svg class="icon icon-anim" aria-hidden="true">
    <use href="img/icons-sprite.svg#ph-download-simple"></use>
  </svg>
  Download PDF
</button>

All icons

The whole Phosphor catalogue: 1512 icons in the light weight. Hover or tap. 118 of them have their own animation today, the rest get a short pop, and data-icon-anim picks any animation you like.

Searches names and meanings, including the tags from the Phosphor catalogue - / puts the cursor in the field, Esc clears it.

The same animation in every weight

The parts of an icon are numbered the same way in thin, light, regular, bold and duotone, so one preset covers them all. The fill weight is built differently, so there the whole icon moves.
