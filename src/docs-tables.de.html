Tabellen & Listen

Vier Wege, eine Liste von Datensätzen zu zeigen - von der klassischen Tabelle bis zur Zeile im Raster. Diese Seite erklärt, was wann die richtige Wahl ist und was jede Variante voraussetzt. Fertige Layouts finden Sie in den Beispielen.

1. Was wählen

Die Wahl läuft auf eine Frage hinaus: Vergleichen Sie Datensätze Spalte für Spalte, oder durchsuchen Sie sie nur.

Komponente Wann Worauf basiert es
.table Daten, die spaltenweise vergleichbar sind: Berichte, Aufstellungen, Rechnungen. <table> - die Tabellensemantik bleibt erhalten.
.data-row Eine Liste von Datensätzen mit Aktionen: Kunden, Projekte, Aufträge. CSS Grid
.data-row-compact Eine dichte Liste mit Icon und zwei Textzeilen - Benachrichtigungen, Dateien, Verlauf. Flexbox
.list-group Eine einfache klickbare Liste von Einträgen: Einstellungsmenü, Auswahl aus einer Liste. Flexbox

Warum das keine Geschmacksfrage ist

<table> trägt Bedeutung: Ein Screenreader kündigt an „Spalte Status, Zeile 3", und der Nutzer kann zellenweise navigieren. Eine aus <div>s gebaute Datensatzliste hat das nicht. Umgekehrt gilt auch: Eine Tabelle, die für ein visuelles Layout verwendet wird, führt den Screenreader in die Irre. Wählen Sie nach den Daten, nicht nach der Optik.

2. Tabellen

Eine Tabelle sitzt immer in .table-wrapper - der sorgt für horizontales Scrollen, wenn es mehr Spalten als Platz gibt. Ohne ihn sprengt eine breite Tabelle die ganze Seite. 

<div class="table-wrapper">
  <table class="table table-hover table-cards">
    <thead class="thead-light">
      <tr><th>Kunde</th><th>Status</th></tr>
    </thead>
    <tbody>
      <tr>
        <!-- data-label ist von .table-cards ERFORDERLICH -->
        <td data-label="Kunde">Molique</td>
        <td data-label="Status"><span class="badge badge-success">Aktiv</span></td>
      </tr>
    </tbody>
  </table>
</div>

Briko Kundenpanel Ausstehend
Klasse Gruppe Was sie macht
.table-wrapper Struktur Container mit horizontalem Scrollen. Umschließen Sie die Tabelle immer damit.
.table Struktur Grundstil: Abstände, Linien, Ausrichtung.
.table-sm Größe Kompakt - mehr Zeilen auf dem Bildschirm.
.table-lg Größe Locker - wenige Zeilen, viel Luft.
.table-striped Aussehen Abwechselnder Zeilenhintergrund.
.table-hover Aussehen Hervorhebung der Zeile unter dem Cursor.
.table-borderless Aussehen Ohne Linien - ruhigere Wirkung.
.thead-light Kopfzeile Gedämpfter Hintergrund (Standardwahl).
.thead-dark Kopfzeile Dunkle Kopfzeile, heller Text.
.thead-primary Kopfzeile Kopfzeile in der Markenfarbe.
.thead-sm Kopfzeile Niedrigere Kopfzeile.
.thead-lg Kopfzeile Höhere Kopfzeile.
.table-cards Mobil Auf dem Smartphone wird jede Zeile zur Karte. Erfordert data-label in jedem <td> - siehe Fallstrick Nr. 1.
.table-cards-always Mobil Dasselbe, aber bei jeder Breite. Für schmale Dashboard-Spalten, in denen die Tabelle nie genug Platz hat.

Abstandsvariablen in Zellen

--table-padding-x, --table-padding-y, --table-font-size und --table-header-font-size stellen die Größenvarianten ein. Sie überschreiben sie selten direkt - dafür gibt es .table-sm und .table-lg, die das konsistent erledigen.

Live-Suche

Das Attribut data-search-target an einem beliebigen Textfeld filtert die Zeilen der angegebenen Tabelle im laufenden Betrieb - ohne Neuladen und ohne eigenes JavaScript. Eine Zeile kann zusätzlich data-tags tragen: die Wörter, nach denen jemand sucht, der sein Problem kennt, aber nicht den Klassennamen. 

<input type="text" class="input" placeholder="Suchen…"
       data-search-target="#kundenBody"
       data-search-status="#zaehler"
       data-search-hotkey="/">
<span id="zaehler"></span>

<table class="table">
  <tbody id="kundenBody">
    <tr><td colspan="2" class="cheat-sheet-category">Aktiv</td></tr>
    <tr data-tags="rechnung zahlung"><td>Molique</td><td>…</td></tr>
  </tbody>
</table>
AttributWirkung
data-search-targetSelektor des Elements mit den Zeilen (meist ein <tbody>). Pflicht - ohne das Attribut startet nichts.
data-tagsAm <tr>. Zusätzliche durchsuchbare Wörter, in der Tabelle unsichtbar.
data-search-statusSelektor des Elements, das die Trefferzahl bekommt („12 von 181").
data-search-emptyEigener Text für den leeren Zustand. Die Vorgabe folgt dem lang des Dokuments (PL/EN/DE).
data-search-hotkeyTaste, die das Feld fokussiert (z. B. /). Optional und bewusst nicht voreingestellt.

Der Abgleich ist kein einfacher Teilstring-Test. Polnisch und Deutsch flektieren am Wortende, deshalb ist das Tag wyśrodkowanie kein Teilstring dessen, was jemand tatsächlich tippt: wyśrodkować. Tags werden daher als Wortstämme gespeichert (wysrodk), und ein Treffer gilt, wenn der Stamm ein Präfix des Suchworts ist oder umgekehrt. Diakritika werden auf beiden Seiten entfernt, so findet wysrodkowac ohne polnische Tastatur dieselben Zeilen. Der sichtbare Zeilentext wird weiterhin als gewöhnlicher Teilstring geprüft.

Eine Abschnittsüberschrift ist ein <tr> mit einer Zelle .cheat-sheet-category - sie verschwindet, sobald darunter nichts mehr übrig ist. Esc leert das Feld, ein ?q= in der Adresse füllt es beim Laden (so lässt sich ein Ergebnis verlinken), und MoliqueTableSearch.refresh() indiziert die Tabelle neu, wenn Zeilen per JS dazukommen. Die Sichtbarkeit schaltet das Attribut hidden, kein Inline-Style.

3. Datenzeilen

Wenn Datensätze nicht verglichen, sondern nur durchgesehen werden - ist eine Tabelle zu starr. Eine Zeile im Raster bricht sich auf einem schmalen Bildschirm selbst um, ohne dass das Layout umgeschrieben werden muss.

Volle Variante

Spalten sind gewöhnliche Kinder von .data-row - wie viele Sie einfügen, so viele wird es geben. Der Aktionsblock rückt an den rechten Rand. 

<div class="data-row">
  <div class="fw-bold">Projektname</div>
  <div class="text-muted">Parameter</div>
  <div><span class="status-dot status-pending">Ausstehend</span></div>
  <div class="data-row-actions">
    <button class="btn-action">Bearbeiten</button>
  </div>
</div>

Kompakte Variante

Sie hat einen von vornherein festgelegten Aufbau: Icon, Inhalt in zwei Zeilen, Aktionen. Dadurch sieht eine Liste von Benachrichtigungen oder Dateien überall gleich aus. Sollen Nutzer diese Liste per Drag neu sortieren können? Siehe die Sortierbare Liste. 

<div class="data-row-compact">
  <div class="row-icon"><span class="icon-square"><svg class="icon" aria-hidden="true"><use href="img/icons-sprite.svg#ph-file-text"></use></svg></span></div>
  <div class="row-content">
    <div class="row-title">Rahmenvertrag.pdf</div>
    <div class="row-details">2,4 MB · gestern</div>
  </div>
  <div class="row-actions">
    <button class="btn-action">Herunterladen</button>
  </div>
</div>
Klasse Variante Was sie macht
.data-row Voll Eine Zeile im Raster; Spalten sind ihre Kinder.
.data-row-actions Voll Button-Block, an den rechten Rand gerückt.
.data-row-compact Kompakt Zeile mit festgelegtem Aufbau: Icon, Inhalt, Aktionen.
.row-icon Kompakt Platz für ein Icon links.
.icon-square Kompakt Quadratischer Hintergrund hinter dem Icon.
.row-content Kompakt Textspalte; nimmt den freien Platz ein.
.row-title Kompakt Erste Zeile - Name des Datensatzes.
.row-details Kompakt Zweite Zeile - Metadaten, gedämpft.
.row-actions Kompakt Buttons rechts.

4. Listen und Zähler

Elementliste

Eine vertikale Liste klickbarer Elemente - Einstellungsmenü, Auswahl aus einer Liste. Der aktuelle Eintrag wird mit .is-active markiert. 

<div class="list-group">
  <a href="#" class="list-group-item is-active">Kontoeinstellungen</a>
  <a href="#" class="list-group-item">Benachrichtigungen</a>
</div>

Icon-Listen

Aufzählungszeichen ersetzt durch ein Icon - typischerweise eine Merkmalsliste bei Preisen. Icon und Farbe wählen Sie über getrennte Klassen, sodass „grüner Haken" und „rotes Kreuz" zwei unabhängige Entscheidungen sind. 

<ul class="list-icons list-icons-check list-icons-success">
  <li>Unbegrenzte Konten</li>
  <li>24/7-Support</li>
</ul>

<ul class="list-unstyled">…</ul>   <!-- reine Liste ohne Aufzählungszeichen -->

Zähler

Eine große Zahl mit Beschriftung - „512 Deployments". Den Zielwert geben Sie als Inhalt von .counter-value an; das Modul js/modules/molique-counters.js zählt danach hoch, sobald das Element ins Sichtfeld scrollt. Ohne JavaScript ist die Zahl trotzdem sichtbar, nur ohne Animation. 

<div class="counter">
  <div class="counter-value">512</div>
  <div class="counter-title">Deployments</div>
</div>
Klasse Was sie macht
.list-group Hülle für die Elementliste.
.list-group-item Ein einzelner Eintrag. .is-active markiert den aktuellen.
.list-unstyled Liste ohne Aufzählungszeichen und Einzug.
.list-icons Aufzählungszeichen ersetzt durch ein Icon.
.list-icons-check Icon: Haken.
.list-icons-arrow Icon: Pfeil.
.list-icons-cross Icon: Kreuz.
.list-icons-success Icon-Farbe: Grün.
.list-icons-danger Icon-Farbe: Rot.
.list-icons-dark Icon-Farbe: kontrastierend zum Hintergrund. Ohne Farbklasse ist das Icon in der Markenfarbe.
.counter Hülle für den Zähler.
.counter-value Die Zahl selbst. Ihre Anwesenheit startet das Hochzähl-Modul.
.counter-title Beschriftung unter der Zahl.

5. Fallstricke

1 .table-cards ohne data-label

Auf dem Desktop sieht alles gut aus, daher zeigt sich der Fehler erst auf dem Smartphone: Die Zeilen werden zu Karten, aber ohne Spaltennamen - es bleiben nur die Werte übrig, einer unter dem anderen. „Aktiv 12.400 € 2026-03-01" - und niemand weiß, was was ist.

CSS nimmt die Beschriftungen ausschließlich aus dem Attribut - es kann sie nicht aus <th> lesen. Wenn Sie eine Tabelle in einer Schleife erzeugen, füllen Sie data-label mit derselben Variable wie die Kopfzeile.

2 Tabelle ohne .table-wrapper

Eine Tabelle bricht ihren Inhalt nicht um, daher sprengt eine breite Tabelle ihr Elternelement und löst eine horizontale Bildlaufleiste für die gesamte Seite aus. Das Symptom kann irreführend sein: „die Seite verschiebt sich auf dem Smartphone", während der Übeltäter eine Tabelle an ganz anderer Stelle ist.

3 In der Tabelle abgeschnittenes Aktionsmenü

.table-wrapper hat sein eigenes Scrollen, daher wird ein aufklappbares Menü neben einer Zeile darin abgeschnitten. Das ist kein Fehler des Wrappers - so funktioniert overflow nun einmal. Verwenden Sie die Dropdown-Variante auf Basis der Popover API: Das Panel landet im Top Layer, außerhalb der Reichweite des Zuschneidens. Details in der Navigation.

4 Eine Tabelle für das Seitenlayout verwendet

Wenn die „Spalten" nicht Merkmale derselben Art sind, belügt <table> den Screenreader - er kündigt Zeilen und Spalten dort an, wo es keine gibt. Für das Layout dient ein Raster: .grid-cols-* oder .data-row.
