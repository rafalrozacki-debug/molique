Input Groups

Fertige Kombinationen aus Feldern mit Text, Icons und Buttons sowie erweiterte Inputs für Datum, Farbe und Bereich.

Gruppierte Felder (Input Groups)

Text, Icons oder Buttons direkt an ein Textfeld anhängen — nützlich bei Suchfeldern und Feldern mit Einheiten.

Preis EUR 
<!-- Suche mit Lupe -->
<div class="input-group">
  <input type="text" class="input" placeholder="Suchen...">
  <!-- FIX: Klasse bg-surface entfernt -->
  <button class="btn text-muted">
    <!-- Lupen-Icon -->
  </button>
</div>

<!-- Feld mit Einheit -->
<div class="input-group">
  <span class="input-group-text">Preis</span>
  <input type="number" class="input" placeholder="0.00">
  <span class="input-group-text">EUR</span>
</div>

Erweiterte Inputs (Datum, Farbe, Bereich)

Individuelle Stile für Datum, Farbe und Bereich, für konsistente Darstellung über verschiedene Browser hinweg.

Klicken Sie auf das Quadrat, um es zu ändern 
<!-- Date Picker -->
<input type="date" class="input">

<!-- Color Picker -->
<input type="color" class="input-color" value="#0d6efd">

<!-- Range Slider -->
<input type="range" class="input-range" min="0" max="100" value="50">

Formularzeile (Inline)

.input-group-inline ordnet Label und Feld nebeneinander in einer Zeile an (statt untereinander) und bricht auf Mobilgeräten sicher um, ohne das Grid zu sprengen. 

<div class="input-group-inline">
  <label for="name">Vollständiger Name</label>
  <input id="name" type="text" class="input">
</div>
