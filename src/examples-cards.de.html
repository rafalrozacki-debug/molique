Karten

Vier fertige molique-Kartenvarianten — von klassisch bis interaktiv mit 3D-Effekt — auf Flexbox aufgebaut, mit automatisch ausgerichteten Footern.

Klassische Karte

Besteht aus einem .card-Container sowie optionalen Elementen: .card-header, .card-body und .card-footer.

Kartentitel

Das ist eine Standardkarte. Flexbox im Inneren sorgt dafür, dass sich der Inhalt sauber anordnet.

Karte mit längerem Text

Diese Karte hat mehr Text. Beachten Sie, dass der Footer der Karte daneben automatisch nach unten gerutscht ist, damit beide Karten im Grid gleich hoch sind! 

<div class="card shadow-sm">
  <div class="card-header">Kartentitel</div>
  <div class="card-body">
    <p>Karteninhalt...</p>
  </div>
  <div class="card-footer">
    <button class="btn btn-primary">Aktion</button>
  </div>
</div>

Featured Box

Eine spezielle Kartenvariante zur Präsentation von Produkt- oder Dienstleistungsmerkmalen. Hat einen dicken oberen Rand und Platz für ein Icon.

🚀

Leistung

Das Framework ist extrem leichtgewichtig, was sich in blitzschnellen Ladezeiten niederschlägt.

✓

Effektivität

Sie bauen eine Oberfläche 3x schneller, als wenn Sie Ihr eigenes CSS von Grund auf schreiben würden. 

<div class="featured-box">
  <div class="featured-box-icon">🚀</div>
  <h4 class="fw-bold">Leistung</h4>
  <p class="text-muted">Beschreibung des Merkmals...</p>
</div>
