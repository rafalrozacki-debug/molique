Kontextmenü

Ein kleines Dropdown-Menü, das sich an den auslösenden Button heftet — mithilfe von CSS Anchor Positioning und der Popover API.

Verankertes Kontextmenü (Anchor Popover)

Nutzt den neuesten CSS-Anchor-Positioning-Standard und die Popover API — Positionierung und Animationen sind reines CSS. 

<!-- 1. Ausloesender Button (definiert den Anker-Namen) -->
<button popovertarget="menu1" style="anchor-name: --btn1;" class="btn btn-secondary">
  Optionen
</button>

<!-- 2. Kontextmenue (verankert sich am Anker) -->
<div id="menu1" popover class="popover-context" style="position-anchor: --btn1;">
  <ul class="popover-action-list">
    <li><button class="popover-action-btn">Bearbeiten</button></li>
    <li><button class="popover-action-btn text-danger">Löschen</button></li>
  </ul>
</div>
