Navigation & Menüs

Zehn Navigationskomponenten — abgesehen vom Theme-Switch und dem Zurück-nach-oben-Button funktionieren alle ohne JavaScript. Diese Seite erklärt die Mechanismen und listet die Klassen; fertige Blöcke zum Kopieren finden Sie in den Beispielen.

1. Was wählen

Alle unten stehenden Komponenten sind unabhängige SCSS-Module — verwenden Sie eine davon nicht, laden Sie sie einfach nicht in Ihr Paket.

Komponente Wofür Worauf basiert es Beispiele
.navbar Die Hauptleiste der Seite. Flexbox Navbar
.navbar-menu-offcanvas Seitlich ausfahrendes Menü auf Mobilgeräten. Checkbox Hack Navbar
.mega-menu Breites, mehrspaltiges Menü. <details> + Anchor Positioning Mega Menu
.dropdown Schmales Menü unter einem Button. <details> oder Popover API Dropdown
.breadcrumb Rückweg durch die Hierarchie. Flexbox Hero-Abschnitte
.pagination Blättern durch Ergebnisseiten. Flexbox Paginierung
.topbar Schmale Leiste über der Navbar (Kontakt, Sprache). Flexbox Navbar
.language-switch Sprachumschalter mit Flaggen. Popover API Language Switch
.theme-switch Umschalter hell/dunkel. Checkbox + JS Navbar
.scroll-to-top Zurück nach oben auf einer langen Seite. JS (Sichtbarkeit) Widgets

2. Navbar — Struktur

Drei Verschachtelungsebenen und nichts weiter: <nav class="navbar"> umschließt .navbar-container (der begrenzt die Inhaltsbreite), und darin sitzen Marke und Menü. Die Höhe der Leiste steckt in der Variable --navbar-h, weil sich auch andere Komponenten darauf beziehen — unter anderem die Sidebar des Admin-Panels. 

<nav class="navbar">
  <div class="container navbar-container">
    <a href="/" class="navbar-brand">Logo</a>
    <div class="navbar-menu">
      <a href="/angebot" class="navbar-item">Angebot</a>
      <a href="/kontakt" class="navbar-item">Kontakt</a>
    </div>
  </div>
</nav>
Logo
Angebot Referenzen Kontakt
Klasse Auf Was sie macht
.navbar <nav> Die Leiste: Hintergrund, Schatten, Höhe --navbar-h.
.navbar-container <div> in der Navbar Verteilt Marke und Menü an die gegenüberliegenden Kanten. Kombinieren Sie sie mit .container, um die Breite zu begrenzen.
.navbar-brand <a> Logo oder Name. Verlinkt üblicherweise zur Startseite.
.navbar-menu <div> Der Link-Container. Seine Anwesenheit aktiviert das Modul zur Hervorhebung der aktiven Position.
.navbar-item <a> Ein einzelner Link. Hat min-height: 44px — die Anforderung an das Berührungsziel.
.navbar-sticky <nav> Heftet die Leiste beim Scrollen oben an. Nicht mit den Overlay-Varianten kombinieren — siehe Fallstrick Nr. 1.
.logo-light / .logo-dark <img> in der Marke Ein Logopaar — das Framework zeigt das zum jeweiligen Theme passende.
.is-active .navbar-item Die aktuelle Seite. Nicht im Markup eintragen — siehe Abschnitt 6.
.is-scrolled <nav> Wird nach dem Scrollen von JS vergeben. Sie setzen sie nie selbst.
.is-hidden .navbar-sticky Verbirgt die angeheftete Leiste beim Scrollen nach unten. Wird ebenfalls von JS vergeben.

3. Overlay-Varianten

Zwei Varianten legen die Navbar auf den Inhalt statt darüber, sodass ein Hero-Foto ganz oben im Fenster beginnen kann. Beide funktionieren gleich: position: absolute über dem Hero, und nach dem Scrollen vergibt JS .is-scrolled, was die Leiste auf position: fixed mit dem Theme-Hintergrund umschaltet.

Klasse Aussehen über dem Hero Nach dem Scrollen
.navbar-transparent Ohne Hintergrund, weiße Links. Theme-Hintergrund, Leiste bündig an der Kante.
.navbar-pill Eine von der Kante abgerückte Pille mit eigenem dunklem Hintergrund. Faltet sich zu einer gewöhnlichen, an der Kante anliegenden Leiste auf.

Variablen der Pille

Die Pille hat separate Variablen für jeden Zustand, nicht eine gemeinsame. Das ist kein Versehen: Ein Inline-Style gewinnt gegen eine Klassenregel, daher würde eine gemeinsame, per style="…" gesetzte Variable den zweiten Zustand für immer blockieren.

Variable Standard Steuert
--navbar-pill-bg dunkel Hintergrund über dem Hero. Dunkel auch im hellen Theme — sie liegt auf einem Foto.
--navbar-pill-color weiß Linkfarbe über dem Hero.
--navbar-pill-bg-scrolled Theme-Hintergrund Hintergrund nach dem Scrollen.
--navbar-pill-color-scrolled Theme-Text Linkfarbe nach dem Scrollen.
--navbar-pill-padding-x 32px Abstand der Pille von der Fensterkante.
--navbar-pill-padding-x-scrolled 16px Abstand nach dem Scrollen. 
<nav class="navbar navbar-pill" style="
       --navbar-pill-bg: #4c1d95;
       --navbar-pill-bg-scrolled: #1e293b;
       --navbar-pill-color-scrolled: #fff;">
  <div class="container navbar-container">…</div>
</nav>

<!-- Die Navbar ist außerhalb des Flusses, also den Inhalt darunter absetzen -->
<header style="padding-top: calc(var(--navbar-h) + 4rem)">…</header>

Beide Varianten in Aktion: Navbar-Beispiele.

4. Offcanvas (mobiles Menü)

Ein Menü, das seitlich ins Bild fährt, ohne eine einzige Zeile JavaScript. Der gesamte Mechanismus ist eine versteckte Checkbox: Hamburger und Hintergrund sind Labels (<label for>) desselben Feldes, und CSS reagiert auf :checked.

Daraus ergibt sich die einzige harte Anforderung: die Checkbox muss ein Geschwister von Hamburger und Menü sein, also innerhalb von .navbar-container liegen. CSS-Selektoren können nur „zur Seite und nach unten" reichen — verschieben Sie die Checkbox vor <nav>, öffnet sich das Menü nicht mehr.

Klasse Auf Was sie macht
.navbar-offcanvas-toggle <input type="checkbox"> Der versteckte Schalter — der Öffnungszustand des Menüs. Erfordert eine id.
.navbar-toggle <label for> Der Hamburger. Enthält drei leere <span>-Elemente — das sind die Striche des Icons.
.navbar-offcanvas-backdrop <label for> Der abgedunkelte Hintergrund. Da es ein Label ist, schließt ein Klick darauf auch das Menü — ebenfalls ohne JS.
.navbar-menu-offcanvas .navbar-menu Verwandelt das Menü auf Mobilgeräten in ein seitlich ausfahrendes Panel.

Vollständiges Markup zum Kopieren: Navbar-Beispiele.

5. Aufklappbare Menüs

Mega Menu und Dropdown basieren auf nativem <details>: <summary> ist der Button, und das Geschwister darunter ist das Panel. Dadurch öffnen sie sich per Klick, nicht bei Hover, sodass die Tastaturbedienung ohne zusätzlichen Aufwand funktioniert.

Das Schließen bei einem Klick außerhalb des Panels ist eine unsichtbare, vollflächige „Abdeckung", die nur vorhanden ist, solange <details> offen ist — der Klick trifft sie, sie leitet ihn an <summary> weiter, und das schließt das Panel nativ.

Das Attribut name statt eines Skripts

Geben Sie allen Menüs in einer Leiste denselben name="nav-mega", und der Browser sorgt selbst dafür, dass höchstens eines offen ist. Bei einer einzelnen Instanz sehen Sie den Effekt nicht — er greift erst ab der zweiten. 

<details class="mega-menu" name="nav-mega">
  <summary class="navbar-item mega-menu-trigger">Komponenten</summary>
  <div class="mega-menu-content">
    <div class="mega-menu-group">
      <h6 class="mega-menu-col-title">Kategorie</h6>
      <a href="#" class="mega-menu-link">Link</a>
    </div>
  </div>
</details>
Klasse Was sie macht
.mega-menu Auf <details>. Die gesamte Komponente.
.mega-menu-trigger Auf <summary>. Kombinieren Sie sie mit .navbar-item, damit sie wie die übrigen Links aussieht.
.mega-menu-content Das Panel. Verankert sich über Anchor Positioning am Trigger.
.mega-menu-group Eine Spalte innerhalb des Panels.
.mega-menu-col-title Die Überschrift der Spalte.
.mega-menu-col-icon Ein Icon neben der Spaltenüberschrift.
.mega-menu-link Ein Link innerhalb einer Spalte.
.mega-menu-featured Ein hervorgehobener Werbeblock im Panel. Darin: .mega-menu-featured-icon, .mega-menu-featured-title, .mega-menu-featured-text, .mega-menu-featured-link.
.dropdown Auf <details>. Das schmale Gegenstück zum Mega Menu.
.dropdown-toggle Auf <summary>.
.dropdown-menu Das Panel mit den Positionen.
.dropdown-item Eine einzelne Position.
.dropdown-menu-end Richtet das Panel an der rechten Kante des Buttons aus.
Dropdown außerhalb der Navbar

In einer Tabelle, einer Karte oder einem Modal schneidet overflow ein auf <details> basierendes Panel zu. Verwenden Sie stattdessen die Variante auf Basis der Popover API: ein gewöhnlicher <button popovertarget="ID"> plus ein .dropdown-menu mit dem Attribut popover und derselben id. Das Panel landet im Top Layer, sodass nichts es zuschneidet, und es verankert sich selbst am Button — ohne .dropdown-Wrapper.

6. Weitere Komponenten

Kleinere Navigationselemente. Jede ist ein eigenes SCSS-Modul, ungenutzte lassen Sie einfach im Paket weg.

Paginierung

<ul class="pagination">
  <li class="page-item is-disabled"><a class="page-link" href="#">Zurück</a></li>
  <li class="page-item is-active"><a class="page-link" href="#">1</a></li>
  <li class="page-item"><a class="page-link" href="#">2</a></li>
  <li class="page-item"><a class="page-link" href="#">Weiter</a></li>
</ul>
Klasse Komponente Was sie macht
.pagination Paginierung Die Liste der Seiten. Auf einem <ul>.
.pagination-modern Paginierung Eine Variante mit auseinandergezogenen, einzelnen Buttons.
.page-item Paginierung Eine Position (<li>). Varianten: .is-active — die aktuelle Seite, .is-disabled — ein nicht verfügbarer Schritt.
.page-link Paginierung Das klickbare <a> innerhalb einer Position.
.breadcrumb Breadcrumbs Der Rückweg. Auf einem <ol> oder <ul>.
.breadcrumb-item Breadcrumbs Ein Glied des Pfads; den Trenner zeichnet CSS. .is-active markiert die aktuelle Stelle.
.topbar Kopfleiste Schmale Leiste über der Navbar — Telefon, E-Mail, Sprache.
.topbar-content Kopfleiste Verteilt den Inhalt an die Kanten der Leiste.
.topbar-list Kopfleiste Horizontale Liste von Positionen ohne Aufzählungszeichen.
.scroll-to-top Zurück nach oben Ein Button in der Ecke. .is-visible vergibt JS nach dem Scrollen — Sie setzen sie nie selbst.
.progress-container-fixed Leseleiste Die Bahn des Fortschrittsbalkens, oben am Fenster fixiert.
.progress-bar-reading Leseleiste Die Füllung, die den Lesefortschritt zeigt. Wird vom Scrollen gesteuert.

Sprachumschalter

Basiert auf der Popover API, daher landet die Liste im Top Layer und kann nicht zugeschnitten werden. Flaggen ausschließlich als SVG-Dateien aus img/flags/ — Emoji werden unter Windows nicht gerendert, und ein externes Sprite funktioniert bei file:// nicht.

Klasse Was sie macht
.language-switch Die Hülle der Komponente.
.language-switch-trigger Der Button mit popovertarget — Flagge und Sprachcode.
.language-switch-menu Die Sprachliste. Kombinieren Sie sie mit .dropdown-menu und dem Attribut popover.
.language-switch-item Eine einzelne Sprache; auch .dropdown-item.
.language-switch-flag Die Flagge als <img> aus img/flags/.
.language-switch-name Der Sprachname neben der Flagge.
.language-switch-check Die Markierung bei der aktuell gewählten Sprache.

Theme-Switch

Ein Hell/Dunkel-Schieberegler, in der Praxis immer ein Nachbar des Sprachumschalters in der Navbar — deshalb hier beschrieben, nicht bei den Formularen. Darunter steckt ein gewöhnliches <input type="checkbox">, eingehüllt in ein <label>, sodass die Tastatur nativ funktioniert.

id="theme-toggle" ist Pflicht

Das ist die einzige Komponente in molique, bei der eine konkrete id Teil des Vertrags ist — molique-script.js sucht das Element über getElementById('theme-toggle'). Ändern oder duplizieren Sie sie, hört der Umschalter auf zu funktionieren, ohne einen Fehler zu melden. Aus demselben Grund darf es auf einer Seite nur einen geben. 

<label class="theme-switch" title="Theme wechseln">
  <input type="checkbox" id="theme-toggle" class="theme-switch-input">
  <div class="theme-switch-track">
    <span class="theme-switch-thumb"></span>
    <div class="theme-icon-wrapper">
      <svg class="theme-icon icon-sun">…</svg>
      <svg class="theme-icon icon-moon">…</svg>
    </div>
  </div>
</label>
Klasse Was sie macht
.theme-switch Die Hülle, auf einem <label> — deshalb schaltet ein Klick an einer beliebigen Stelle das Theme um.
.theme-switch-input Die versteckte, zustandshaltende Checkbox. Sie benötigt id="theme-toggle".
.theme-switch-track Die Bahn des Schiebereglers — die sichtbare, umrandete Pille.
.theme-switch-thumb Das schwebende Element, das auf der Bahn entlangfährt.
.theme-icon-wrapper Der Container für beide Icons innerhalb der Bahn.
.theme-icon Der gemeinsame Icon-Stil — Größe und Übergang.
.icon-sun Das Icon für das helle Theme.
.icon-moon Das Icon für das dunkle Theme.
Was das Skript macht Detail
Merkt sich die Wahl Der Schlüssel molique-theme in localStorage.
Respektiert die Systemeinstellung Beim ersten Besuch wird prefers-color-scheme gelesen. Eine gespeicherte Nutzerwahl hat Vorrang.
Schaltet das Theme um Setzt data-theme auf <html> — das ist der einzige Unterschied zwischen den Themes.
Sanfter Übergang Die View Transitions API führt einen Cross-Fade auf der GPU aus. Ältere Browser und prefers-reduced-motion erhalten einen sofortigen Wechsel.

7. Aktive Position

Die Navbar ist üblicherweise eine einzige, von allen Unterseiten gemeinsam genutzte Datei, daher lässt sich die aktuelle Position nicht im Markup markieren — sie wäre überall gleich markiert. Das übernimmt das Modul js/modules/molique-navbar-active.js, automatisch geladen, sobald eine Seite ein .navbar-menu enthält.

Erhält .is-active Wann
.navbar-item Wenn sein href auf die aktuelle Adresse zeigt.
.dropdown-item, .mega-menu-link Ebenso — auch innerhalb aufklappbarer Panels.
Das <summary> eines Panels Wenn der aktive Link darin liegt — man sieht, in welchem Zweig man sich befindet.

Erscheint dieselbe Seite gleichzeitig in mehreren Menüs, werden alle Vorkommen hervorgehoben. Die vertikale Sidebar des Admin-Panels wird von einem separaten Modul behandelt — siehe Admin-Panel.

8. Fallstricke

1 Overlay plus .navbar-sticky = das Overlay verschwindet

.navbar-transparent und .navbar-pill funktionieren, weil sie außerhalb des Dokumentflusses liegen (position: absolute) — deshalb kann Inhalt darunter geraten. .navbar-sticky macht das Gegenteil: Es kehrt in den Fluss zurück. Es gewinnt in der Kaskade, und der gesamte Overlay-Effekt geht verloren. 

<!-- FALSCH - sticky löscht das Overlay -->
<nav class="navbar navbar-transparent navbar-sticky">

<!-- RICHTIG - das Anheften nach dem Scrollen ist bereits eingebaut -->
<nav class="navbar navbar-transparent">
2 Inhalt verbirgt sich unter einer Overlay-Navbar

Da die Leiste außerhalb des Flusses liegt, reserviert sie sich keinen Platz — das erste Element der Seite rutscht darunter. Bei einem Foto-Hero ist das beabsichtigt, bei einem gewöhnlichen Abschnitt nicht. Rücken Sie den Inhalt um die Höhe der Leiste ab. 

<header style="padding-top: calc(var(--navbar-h) + 4rem)">…</header>
3 Offcanvas-Checkbox aus dem Container herausverschoben

Es ist verlockend, das <input> vor <nav> zu platzieren, „damit es nicht stört". Dann öffnet sich das Menü nicht mehr, und es ist kein Fehler zu sehen — es passiert einfach nichts. CSS verbindet die Checkbox über einen Geschwister-Selektor mit dem Menü, daher müssen beide im selben .navbar-container sitzen.

4 .is-active fest im Navbar-Markup eingetragen

Die Navbar ist oft eine einzige Datei für die gesamte Website. Eine fest markierte Position wird auf jeder Unterseite hervorgehoben — auch auf denen, auf denen Sie sich woanders befinden. Überlassen Sie das dem Modul aus Abschnitt 6.

Dieselbe Regel gilt für die gerade von Ihnen gelesene Dokumentations-Sidebar — deshalb ist sie ein einziges Partial ohne .is-active im Code.

5 Ein Dropdown, das in einer Tabelle oder einem Modal zugeschnitten wird

Ein auf <details> basierendes Panel ist ein gewöhnliches Element im Baum, daher schneidet ein overflow: hidden oder overflow: auto an einem Vorfahren es ab. Typischerweise passiert das in .table-wrapper und in Modalen. Die Lösung ist die in Abschnitt 5 beschriebene Variante auf Basis der Popover API — das Panel landet im Top Layer, außerhalb der Reichweite von overflow.
