Getting Started

Poznaj molique – ultralekki, rygorystycznie zoptymalizowany framework CSS B2B. Zbudowany na natywnych warstwach kaskadowych (@layer), bez wojen na specyficzność i z inteligentnym autoloaderem JS.

🎨 Theme Editor

Dobierz kolory, typografię, zaokrąglenia i sidebar na żywo, a potem skopiuj gotowy blok :root do swojego projektu.

Otwórz edytor motywu ➔ Pobierz ⬇

1. Szablon Startowy (Boilerplate)

Skopiuj poniższy kod HTML, aby rozpocząć pracę. Zawiera on zoptymalizowane ładowanie fontów (Variable Fonts) oraz główny plik rdzenia.

Ważne informacje:
  • Plik molique-script.js musi posiadać atrybut defer, aby nie blokować renderowania strony.
  • Tagi <link rel="preload"> zapobiegają skokom tekstu (FOUT/FOIT) podczas ładowania niestandardowych fontów. 
<!DOCTYPE html>
<html lang="pl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Mój Projekt molique</title>

  <!-- Preload Variable Fonts -->
  <link rel="preload" href="fonts/inter-variable.woff2" as="font" type="font/woff2" crossorigin>
  <link rel="preload" href="fonts/poppins-variable.woff2" as="font" type="font/woff2" crossorigin>

  <!-- Główne style frameworka -->
  <link rel="stylesheet" href="css/molique-style.css">
  <!-- Twoje nadpisania (Opcjonalne) -->
  <link rel="stylesheet" href="css/custom.css">
</head>
<body>

  <h1 class="text-9 fw-black">Witaj w molique!</h1>

  <!-- Główny skrypt (Autoloader) -->
  <script src="js/molique-script.js" defer></script>
</body>
</html>

2. Struktura Plików i Autoloader JS

Framework został zaprojektowany z myślą o ekstremalnej wydajności. Nie ładujemy kodu, którego nie używasz.

Jak działa DOM-based Lazy Loading?

W pliku HTML linkujesz tylko jeden plik JavaScript: molique-script.js. Ten plik skanuje strukturę strony. Jeśli wykryje, że użyłeś np. klasy .carousel, automatycznie i asynchronicznie pobierze plik js/modules/molique-carousel.js. Dzięki temu każda podstrona ładuje tylko niezbędne bajty.

3. Konfiguracja Zmiennych (Variables)

Cały framework opiera się na zmiennych CSS (Custom Properties). Aby dostosować wygląd do swojej marki, wystarczy nadpisać blok :root w swoim pliku custom.css. Nie musisz rekompilować SCSS! 

/* Twój plik custom.css */
:root {
  /* Główne kolory marki */
  --primary: #f97316; 
  --primary-hover: #ea580c;
  --primary-rgb: 249, 115, 22;

  /* Promień zaokrąglenia dla wszystkich komponentów */
  --border-radius: 8px;

  /* Wymuszenie dostępności B2B (obszar klikalny) */
  --target-size-min: 44px;
}

4. Architektura Warstw (@layer)

Framework używa natywnych warstw CSS. Oznacza to, że klasy narzędziowe (Utilities) zawsze wygrywają z komponentami, bez użycia toksycznego !important.

Karta domyślnie ma tło --bg-surface

Ale klasa .bg-dark wygrywa dzięki warstwie @layer utilities! 

<!-- Klasa .bg-dark nadpisuje tło karty bez !important -->
<div class="card p-4 bg-dark text-white">
  <h3>Karta domyślnie ma tło --bg-surface</h3>
</div>

5. Wybór Modułów CSS

Molique jest modularny. Główne style ładujesz zawsze, ale zaawansowane komponenty (Sklep, Blog, Panel Admina) posiadają własne, niezależne pliki CSS. 

<head>
  <!-- 1. Rdzeń frameworka (Wymagany) -->
  <link rel="stylesheet" href="css/molique-style.css">
  
  <!-- 2. Moduły opcjonalne (Ładuj tylko tam, gdzie potrzebujesz) -->
  <link rel="stylesheet" href="css/molique-style-admin.css">
  <link rel="stylesheet" href="css/molique-style-shop.css">
  <link rel="stylesheet" href="css/molique-style-blog.css">
</head>

6. Wymagania i Kompatybilność

Framework wykorzystuje najnowsze standardy W3C. Nie wspieramy przeglądarki Internet Explorer.

Wykorzystywane technologie:
  • CSS Cascade Layers (@layer): Pełne wsparcie w Chrome 99+, Safari 15.4+, Firefox 97+.
  • Relacyjny selektor (:has()): Pełne wsparcie w Chrome 105+, Safari 15.4+, Firefox 121+.
  • Scroll-Driven Animations: (np. Parallax) Działają natywnie w Chrome 115+. W starszych przeglądarkach framework automatycznie uruchamia lekki fallback w JavaScript.
  • Natywne Modale (<dialog>): Pełne wsparcie we wszystkich nowoczesnych przeglądarkach.
