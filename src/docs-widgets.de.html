Widgets (Opt-in)

Fünf unabhängige, fortgeschrittene Widgets. Drei benötigen eine eigene CSS-Datei (oben auf dieser Seite aufgeführt) — die JS-Logik binden Sie nie manuell ein: molique-script.js erkennt das Widget an seiner Klasse auf der Seite und lädt selbst das passende Modul aus js/modules/ nach.

1. Was wählen

Widget Wann Benötigt CSS-Datei
.before-after-slider Umgestaltungen, Projekte, Retusche — Vergleich zweier Fotos. molique-style-before-after.css
.btn-magnetic Ein CTA-Button, der den Cursor auf dem Desktop „anziehen" soll. Keine — nur JS.
.speed-dial Ein schwebender Aktions-Button (FAB) mit ein paar Kurzbefehlen. molique-style-speed-dial.css
.share-bar Teilen eines Artikels in sozialen Medien. molique-style-share.css
.scroll-to-top Rückkehr an den Anfang einer langen Seite. Keine — eine Kernkomponente.

2. Vorher / Nachher-Slider

Ein verstecktes <input type="range"> über der gesamten Widget-Fläche steuert die CSS-Variable --position — sie bewegt die Linie und den Griff und schneidet das „Vorher"-Foto per clip-path zu. Ein natives Range-Element liefert Tastaturbedienung (Pfeiltasten) ganz ohne zusätzlichen Code. 

<div class="before-after-slider">
  <img src="nachher.jpg" class="before-after-img img-after" alt="Nachher">
  <img src="vorher.jpg" class="before-after-img img-before" alt="Vorher">
  <input type="range" class="slider-control" min="0" max="100" value="50">
  <div class="slider-line"></div>
  <div class="slider-handle"></div>
</div>
Klasse Was sie tut
.before-after-slider Die Hülle. Träger der Variable --position (Standard 50%).
.img-after Das „Nachher"-Foto — die untere Ebene, im normalen Fluss (bestimmt die Höhe des Widgets).
.img-before Das „Vorher"-Foto — die obere Ebene, per clip-path entsprechend --position zugeschnitten. Die Reihenfolge der Klassen im HTML ist beliebig — über die Ebenen entscheidet z-index, nicht die DOM-Reihenfolge.
.slider-control Das unsichtbare input[type=range] über der gesamten Fläche — der eigentliche Regler.
.slider-line / .slider-handle Rein visuell — sie folgen --position und fangen keine Klicks ab (pointer-events: none).

3. Magnetischer Button

Fügen Sie .btn-magnetic zu einem beliebigen Element hinzu — es folgt dem Cursor innerhalb seines Hover-Radius. Die Klasse hat kein eigenes CSS: Der gesamte Effekt ist ein inline style="transform: translate(…)", das JS bei jedem mousemove setzt. 

<button class="btn-primary btn-magnetic">
  Magnetischer Button
</button>

Nur Geräte mit Zeigegerät

Das Skript prüft matchMedia('(pointer: fine)') und hängt den Listener bei Touch (Telefon, Tablet) gar nicht erst ein — der Button verhält sich ganz normal, ohne jede Spur des Effekts.

4. Speed Dial

Ein schwebender Aktions-Button (FAB) mit versteckten Kurzbefehlen. Er klappt bei :hover des GESAMTEN Widgets AUF, oder wenn eines seiner Kinder Fokus erhält (z. B. nach dem Klick auf den Hauptbutton) — funktioniert also mit Maus, Touch und Tastatur. Null JavaScript. 

<!-- Standardmäßig position: fixed; bottom/right: 30px -->
<div class="speed-dial">
  <div class="speed-dial-actions">
    <button class="speed-dial-action" aria-label="E-Mail schreiben"><svg class="icon" aria-hidden="true"><use href="img/icons-sprite.svg#ph-envelope-simple"></use></svg></button>
    <button class="speed-dial-action" aria-label="Anrufen"><svg class="icon" aria-hidden="true"><use href="img/icons-sprite.svg#ph-phone"></use></svg></button>
  </div>
  <button class="speed-dial-main">+</button>
</div>
Klasse Was sie tut
.speed-dial position: fixed unten rechts — fest, ohne Klasse zum Ändern der Ecke (siehe Fallstrick Nr. 1).
.speed-dial-main Der runde Hauptbutton, 56px.
.speed-dial-actions Der Container der Kurzbefehle — standardmäßig unsichtbar (opacity: 0; visibility: hidden).
.speed-dial-action Ein einzelner runder Kurzbefehl, 44px.

5. Teilen-Widget

Eine Leiste mit Social-Media-Buttons. Der Wert data-network entscheidet über das Verhalten — facebook/twitter/linkedin/whatsapp öffnen ein Popup mit Share-Link, native ruft das systemeigene Teilen-Fenster auf (Web Share API). 

<div class="share-bar">
  <button class="share-btn" data-network="facebook">f</button>
  <button class="share-btn" data-network="twitter">t</button>
  <button class="share-btn" data-network="native"><svg class="icon" aria-hidden="true"><use href="img/icons-sprite.svg#ph-export"></use></svg></button>
</div>
Klasse / Attribut Was sie tut
.share-bar Die Hülle. Standardmäßig als schwebende vertikale Leiste positioniert — in der Demo oben per Inline-Style auf horizontal, im Kontext, umgestellt.
.share-btn Ein einzelner Button. Er, nicht .share-bar, ist der Selektor, der den Autoloader auslöst.
data-network facebook / twitter / linkedin / whatsapp / native. Ein anderer Wert — der Button tut nichts.

6. Nach oben scrollen

Ein einziger Button, einmal am Ende von <body> eingefügt. Sichtbarkeit und Scrollen werden dauerhaft vom Kern molique-script.js übernommen (wie der Sidebar-Umschalter im Admin-Panel) — es gibt kein separates Modul zum Registrieren.

Erzwungene Klasse .is-visible — normalerweise nach 400px Scrolltiefe erreicht. 

<button class="scroll-to-top" aria-label="Nach oben">
  <svg class="icon" aria-hidden="true"><use href="img/icons-sprite.svg#ph-arrow-up"></use></svg>
</button>
Klasse Was sie tut
.scroll-to-top position: fixed, unten rechts. Unsichtbar, bis es .is-visible erhält.
.is-visible Wird vom Skript nach mehr als 400px Scrolltiefe gesetzt. Klick: window.scrollTo({ top: 0, behavior: 'smooth' }).

7. Fallstricke

1 .speed-dial und .scroll-to-top auf derselben Seite

Beide haben identische Standardkoordinaten — position: fixed; bottom: 30px; right: 30px; — zusammen verwendet landen sie also genau übereinander (.scroll-to-top obenauf, höherer z-index). Wenn Sie beide brauchen, verschieben Sie eines mit einem eigenen style oder einer CSS-Regel, z. B. bottom: 100px.

2 Fotos mit unterschiedlichem Seitenverhältnis im Vorher/Nachher-Slider

Die Höhe des Widgets wird von .img-after bestimmt (height: auto, natürliches Seitenverhältnis). .img-before hat ein erzwungenes height: 100% — weicht sein Seitenverhältnis vom „Nachher"-Foto ab, wird es gegenüber dem Original gestreckt oder gestaucht.

3 Fehlende Web Share API endet in einem nativen alert()

Der Button data-network="native" zeigt in einem Browser ohne Unterstützung (ältere Desktop-Chrome- und Firefox-Versionen) ein blockierendes alert('Ihr Browser unterstuetzt…') statt sich still zu verstecken oder auf eine andere Option umzuschalten. Wenn Ihre Zielgruppe hauptsächlich am Desktop ist, ziehen Sie in Betracht, diesen Button zugunsten konkreter Netzwerke wegzulassen.
