Auf npm

CLI molique-jit

Die Kommandozeile, mit der Sie die molique JIT-Engine bedienen: Bauen, Live-Watch-Modus, Konfiguration — dazu 8 Generatoren für fertige HTML-Bausteine.

1. Installation

Das Paket ist auf npm als molique-jit veröffentlicht. Meist genügt eine Dev-Abhängigkeit: 

npm install --save-dev molique-jit

Oder ohne Installation, einmalig über npx: 

npx molique-jit init
npx molique-jit build

Paketseite: npmjs.com/package/molique-jit. Der Quellcode liegt offen im Repository: github.com/rafalrozacki-debug/molique.

2. Die Datei molique.config.mjs

Der Befehl init erstellt diese Datei für Sie, mit Kommentaren zu jedem Feld. Ein vollständiges, handgeschriebenes Beispiel: 

// molique.config.mjs
export default {
  // Wo nach Klassennamen gesucht wird.
  content: ['**/*.html', '**/*.php'],

  // Wohin das erzeugte CSS geschrieben wird.
  output: 'css/molique-jit.css',

  // NUR projektspezifische Klassen (z. B. in PHP zusammengesetzt).
  // molique-eigene Runtime-Klassen (Toasts, Karussell, .is-*-Zustände)
  // müssen hier nicht aufgeführt werden — die Engine bindet sie automatisch ein.
  safelist: ['badge-success', 'badge-danger'],

  minify: true,
};

Bei mehreren unabhängigen Seiten in einem Projekt (z. B. der Hauptseite und einer separaten Kampagnen-Landingpage) ersetzt das Feld targets die obigen content/output-Felder und baut jedes Ziel unabhängig — die Landingpage bekommt ihre eigene, kleine CSS-Datei, ohne den Rest: 

export default {
  targets: [
    { content: ['src/**/*.html'], output: 'css/molique-jit.css' },
    { content: ['landing-kampagne.html'], output: 'css/landing-kampagne.css' },
  ],
};
Feld Standard Beschreibung
content ['**/*.html', '**/*.php'] Wo nach Klassen gesucht wird (Glob-Muster).
output css/molique-jit.css Pfad der Ausgabedatei.
safelist [] Klassen Ihres Projekts, die der Scan übersehen könnte (z. B. im Backend zusammengesetzt).
minify true Aktuell praktisch wirkungslos — die Quelldaten sind bereits an der Quelle komprimiert.
targets — Eine Liste unabhängiger Builds; wenn vorhanden, ersetzt sie content/output.

3. Engine-Befehle

Die Binärdatei heißt molique-jit (nicht nur molique), um Kollisionen mit anderen Tools mit kürzerem Namen zu vermeiden. Das CLI versteht Befehle auf Englisch, aber auch ihre polnischen und deutschen Entsprechungen — praktisch für Teams, die im Alltag eine dieser Sprachen verwenden.

Englisch (kanonisch) Polnisches Alias Deutsches Alias Was es tut
init start start Erstellt eine molique.config.mjs mit einer Beispielkonfiguration.
build buduj bauen Kompiliert CSS einmalig in die Ausgabedatei(en).
watch obserwuj beobachten Beobachtet Dateien und baut live neu (~50ms Debounce).
--minify / -m --minifikuj --minifizieren Erzwingt die Komprimierung der Ausgabe.
--config / -c --konfiguracja --konfiguration Verweist auf einen eigenen Konfigurationsdateipfad.

Alle drei Sprachvarianten tun genau dasselbe:

npx molique-jit init
npx molique-jit build --minify
npx molique-jit watch --config ./custom.config.mjs
npx molique-jit start
npx molique-jit buduj --minifikuj
npx molique-jit obserwuj --konfiguracja ./custom.config.mjs
npx molique-jit start
npx molique-jit bauen --minifizieren
npx molique-jit beobachten --konfiguration ./custom.config.mjs

Exit-Codes

build endet bei Erfolg mit dem Code 0 und bei einem Fehler mit 1 (z. B. wenn die Konfiguration auf einen nicht existierenden Ordner verweist) — praktisch zur Einbindung in CI, etwa als Schritt vor der Veröffentlichung.

4. Komponenten-Generatoren: make:*

Eine eigenständige Befehlsfamilie, unabhängig vom CSS-Build. Jeder Befehl startet einen interaktiven Assistenten im Terminal (Pfeiltasten + Enter) und gibt am Ende einen fertigen, einfügbaren HTML-Block aus — zeichengenau identisch mit den echten, funktionierenden Beispielen in dieser Dokumentation. make:component selbst erzeugt nichts — es gibt eine Liste aller verfügbaren Generatoren aus, damit Sie sich die Namen nicht merken müssen: 

npx molique-jit make:component
Befehl Polnisches Alias Deutsches Alias Erzeugt
make:modal zrob:modal mache:modal Modal (<dialog>) — Standard / Confirm / Context
make:layout zrob:uklad mache:layout Seitengerüst — Admin Dashboard / Hero (Simple + Cutout) / Bento Grid
make:nav zrob:nawigacje mache:nav Navbar — Offcanvas, 3 Hintergrundvarianten, optional Mega Menu / Theme Switch / Language Switch
make:table zrob:tabele mache:tabelle B2B-Tabelle mit automatischem data-label auf Mobile
make:chart zrob:wykres mache:diagramm CSS/SVG-Diagramm — Radial Bar / Funnel / Pipeline / Stock Bar
make:form zrob:formularz mache:formular Formular — Floating Labels / Klassisch, optional Searchable Select / Premium Multi Select / Drag & Drop File Upload
make:popover zrob:popover mache:popover Kontextmenü .popover-context (CSS Anchor Positioning)
make:widget zrob:widget mache:widget Speed Dial / Before-After Slider / Stepper / Share Bar
make:component — Gibt diese Liste aus (kein Generator)

Die Option -n, --count

Jeder Generator, der eine Liste variabler Länge erzeugt (Menüpunkte, Tabellenzeilen, Diagrammschritte …), akzeptiert -n, --count <n> — überspringt NUR die Frage „wie viele?", der Rest des Assistenten (Beschriftungen, Varianten, Farben) bleibt weiterhin interaktiv: 

npx molique-jit make:modal
npx molique-jit make:table --count 5

Am Ende jedes Generators wählen Sie, ob der Code direkt in der Konsole ausgegeben wird (zum Kopieren mit der Maus) oder in einer Datei gespeichert wird — das Tool überschreibt eine vorhandene Datei nie ohne ausdrückliche Bestätigung.
