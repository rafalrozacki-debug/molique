Stock Bar (Segmentierter Lagerbestand)

Eine fünfsegmentige Füllstandsanzeige — Lagerbestände, Limits, Quoten. Null JS und keine zusätzlichen Elemente: Die Segmente werden von einer SVG-Maske gezeichnet, und die Anzahl der gefüllten Segmente wird vom Backend über die Variable style="--stock-filled: 3" (0–5) übergeben. Leere Segmente sind eine Abtönung der Variantenfarbe, sodass die Komponente auch im Dark Mode funktioniert. Geben Sie den Wert daneben als Text an (oder vergeben Sie role="img" + aria-label) — der Balken selbst ist rein visuell.
