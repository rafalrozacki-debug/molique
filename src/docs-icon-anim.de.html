Animierte Phosphor-Icons (Opt-in)

Ein eigenes Modul, das die Phosphor-Icons zum Leben erweckt, die molique ohnehin verwendet: Die Glocke schwingt, das Herz schlägt. Es bewegt die einzelnen Teile eines Icons, nicht nur das Ganze. Ausgelöst wird die Animation durch Hover, Antippen, Hereinscrollen oder eine eigene Klasse, und der Auslöser kann auf dem Button, der Karte oder dem Link sitzen, der das Icon enthält.

Framework: molique

Der Autor von molique ist Rafał Różacki.

Icons: Phosphor Icons

Die Icons wurden von Helena Zhang und Tobias Fried gestaltet. Die Familie Phosphor Icons steht unter der MIT-Lizenz (© Phosphor Icons). Dieses Modul enthält keine Icon-Geometrie, es bewegt nur die Icons, die du bereits hast. Es ist kein Projekt des Phosphor-Teams und wird von ihm nicht unterstützt.

1. Installation

Du bindest eine CSS-Datei ein. Die JS-Logik lädt molique-script.js nach, sobald auf der Seite mindestens ein .icon-anim steht, genau wie bei den anderen Widgets. 

<link rel="stylesheet" href="css/molique-style-icon-anim.css">

<svg class="icon icon-anim icon-anim-hover" aria-hidden="true">
  <use href="img/icons-sprite.svg#ph-bell"></use>
</svg>

Woher die Icons kommen

Phosphor veröffentlicht jede Strichstärke in zwei Formen, und davon hängt ab, wie viel sich bewegen lässt.

Quelle Was sich bewegt Hinweise
Ein Sprite <use href="…#ph-bell"> aus den Strich-Icons (Ordner raw/ in phosphor-icons/core) Das ganze Icon und seine Teile, Strichzeichnung So arbeitet molique.dev. Das JS kopiert die Formen des Symbols in das <svg>. Das Sprite muss auf derselben Domain liegen.
SVG direkt ins HTML eingefügt, aus derselben Quelle Das ganze Icon und seine Teile, Strichzeichnung Ergänze data-icon="bell" - aus den Formen lässt sich der Name nicht ablesen.
Abgeflachte SVGs (assets/, npm-Paket @phosphor-icons/core) Das ganze Icon Jedes Icon ist ein einziger Konturpfad. Es gibt keine einzelnen Teile.
Der Webfont <i class="ph ph-bell"> (@phosphor-icons/web) Das ganze Icon Den Namen liest das JS aus der Klasse ph-bell. Eine Glyphe ist ein Zeichen.

Die Teile sind in thin, light, regular, bold und duotone gleich nummeriert, ein Preset funktioniert also in allen. Der Hintergrund von duotone zählt nicht mit. Die Strichstärke fill ist anders aufgebaut und bekommt nur die Animation des ganzen Icons.

2. Auslöser

Eine Auslöserklasse wirkt auf dem Icon selbst oder auf einem beliebigen Vorfahren. Der zweite Fall ist der übliche: Du fährst über den ganzen Button, und das Icon darin bewegt sich.

Schleife mit Pause 
<!-- Auf dem Icon selbst -->
<svg class="icon icon-anim icon-anim-hover"><use href="…#ph-bell"></use></svg>

<!-- Auf dem Elternelement: Hover über den ganzen Button -->
<button class="btn-primary icon-anim-hover">
  <svg class="icon icon-anim"><use href="…#ph-download-simple"></use></svg>
  Angebot herunterladen
</button>

<!-- Antippen: spielt bis zum Ende, auch nach kurzem Tippen -->
<button class="btn-outline-danger icon-anim-tap">…</button>

<!-- Immer, in Schleife, mit 800 ms Pause zwischen den Runden -->
<span class="icon-anim-play icon-anim-loop" data-icon-anim-loop-delay="800">…</span>
Klasse / Attribut Was sie tut
.icon-anim Das Icon, das sich bewegen soll. Auf einem <svg> oder auf <i class="ph ph-…">. Animiert allein nichts, sie wartet auf einen Auslöser.
.icon-anim-hover Animiert beim Überfahren mit dem Zeiger (nur auf Geräten mit Hover) und beim Tastaturfokus (:focus-visible). Auf dem Smartphone ergänze .icon-anim-tap.
.icon-anim-tap Animiert beim Drücken (Zeiger, Enter, Leertaste) und spielt bis zum Ende. In der Schleife bis zum Loslassen. Das JS setzt dafür .is-tapped.
.icon-anim-view Animiert, wenn das Element ins Bild scrollt (das JS setzt .is-in-view). Standardmäßig einmal. data-icon-anim-once="false" wiederholt bei jedem Hereinscrollen, data-icon-anim-margin ist die rootMargin des Observers.
.icon-anim-play Animiert sofort und so lange, wie die Klasse am Element ist. Zur Steuerung aus eigenem JS, z. B. ein Status-Icon „wird gespeichert“.

3. Animationen

Über tausend Icons haben eine Standardanimation, die zu dem passt, was sie zeigen. Das Auto fährt, die Flamme flackert, das Zahnrad dreht sich, und ein Pfeil geht dorthin, wohin sein Name sagt. Fast 600 bewegen nur einen Teil: Der Pfeil im Rahmen geht, der Rahmen bleibt, der Schrägstrich zeichnet sich über das Icon, Buchstaben und Ziffern schreiben sich selbst, die WLAN-Bögen breiten sich von der Mitte aus, die Zeiger laufen über das Zifferblatt. 226 Icons pulsieren kurz: Markenlogos, religiöse Symbole und Gegenstände ohne natürliche Bewegung. Eine andere Animation als die Standardanimation

data-icon-anim="name" überschreibt das Preset des Icons. Die Animationen unten bewegen das ganze Icon und funktionieren daher mit jeder Quelle und jeder Strichstärke. Ausnahmen sind draw und draw-loop, die die Striche zeichnen und die Teile brauchen. Ohne sie pulsiert das Icon nur.

draw draw-loop tada flip float 
<svg class="icon icon-anim icon-anim-hover" data-icon-anim="draw">
  <use href="img/icons-sprite.svg#ph-house"></use>
</svg>

zoom-in, zoom-outVergrößern und zurück / Verkleinern und zurück.
nudge-right, nudge-left, nudge-up, nudge-downEin Stoß in die Richtung und zurück.

4. Zeit, Schleife und Vererbung

Die Modifikatoren sind CSS-Variablen und vererben sich wie die Textfarbe. .icon-anim-loop auf einer Werkzeugleiste lässt jedes Icon darin in Schleife laufen, und ein einzelnes Icon kann das mit einem eigenen Wert überschreiben.

Klasse / Token Was sie tut
.icon-anim-loop Wiederholt endlos (--icon-anim-iterations: infinite). Ein Icon in Schleife außerhalb des Bildschirms wartet (das JS setzt .is-offscreen).
data-icon-anim-loop-delay="600" Pause in Millisekunden nach jeder Runde. Auf dem Icon oder einem Vorfahren. Während der Pause kehrt das Icon zu seinem normalen Aussehen zurück.
.icon-anim-persist Behält das letzte Bild nach dem Ende (--icon-anim-fill: forwards).
.icon-anim-fast / .icon-anim-slow Doppelt so schnell / halb so schnell.
--icon-anim-speed Tempo-Faktor, standardmäßig 1. 2 ist doppelt so schnell.
--icon-anim-delay Startverzögerung, standardmäßig 0s. 
<div class="icon-anim-hover">
  <svg class="icon icon-anim">…</svg>
  <svg class="icon icon-anim icon-anim-slow">…</svg>
  <svg class="icon icon-anim" style="--icon-anim-delay: 0.3s">…</svg>
</div>

5. Barrierefreiheit und API

Bei prefers-reduced-motion: reduce stehen die Icons still. Jede Regel, die etwas bewegt, steht in @media (prefers-reduced-motion: no-preference), es gibt also nichts zu überschreiben. Hover reagiert auch auf den Tastaturfokus, und ein dekoratives Icon braucht wie jedes andere aria-hidden="true".

Später hinzugefügte Icons (ein Toast, ein per fetch befülltes Modal) erkennt das Modul selbst. Aus eigenem JS: 

// eine Runde der Animation, z. B. nach dem Speichern eines Formulars
window.moliqueIconAnim.play(document.querySelector('#save-icon'));

// ein Fragment von Hand vorbereiten (meist unnötig)
window.moliqueIconAnim.hydrate(container);

6. Fallstricke

1 Ein Sprite von einer anderen Domain oder einem CDN

Browser zeichnen kein <use> von einem anderen Origin, und das Modul lädt das Sprite von derselben Adresse wie im href. Lege das Sprite auf dieselbe Domain wie die Seite. Schlägt das Laden fehl, behält das Icon sein <use> und bewegt sich nur als Ganzes.

2 Ein eingefügtes SVG aus dem abgeflachten Satz hat keine Teile

Die Dateien aus assets/ (npm) und der Font sind eine einzige Kontur. Das Preset für Mülleimer oder Schloss findet dort nichts, das Icon bekommt nur die Animation des Ganzen. Für Teilanimationen nimm die Strichdateien aus raw/: Elemente <line>, <path> und <polyline> mit stroke="currentColor".

3 .icon-anim-view und Hover auf demselben Element

Nach dem Hereinscrollen bleibt .is-in-view am Element, der Zustand „animieren“ ist also schon an, und ein Hover startet die Animation kein zweites Mal. Brauchst du beides, setze den Sichtbarkeits-Auslöser auf den Container und den Hover auf den Button darin.
