Durchsuchbares Select

Erweiterte Auswahl-Steuerelemente für B2B-Systeme — von einer durchsuchbaren Combobox bis hin zu einem Premium-Multi-Select mit Kategorien.

Durchsuchbares Select (Combobox)

Ersetzt das klassische <select>-Tag. Das Öffnen und Schließen funktioniert nativ über die Popover API — das Menü wird im Top Layer gerendert und somit selbst innerhalb eines Modals nicht abgeschnitten.

<div class="select-search">
  <button type="button" class="input select-search-trigger" popovertarget="kunde-select">
    <span>Aus der Liste wählen...</span>
  </button>

  <!-- [popover] = Top Layer: Menü wird nicht abgeschnitten, selbst im Modal -->
  <div class="select-search-menu" popover id="kunde-select">
    <input type="text" class="input select-search-input" placeholder="Suchen...">
    <div class="select-search-list">
      <div class="select-search-option" data-value="1">Option 1</div>
      <div class="select-search-option" data-value="2">Option 2</div>
    </div>
  </div>

  <!-- Verstecktes Feld für das Backend -->
  <input type="hidden" name="kunde_id" class="select-search-hidden">
</div>

Einfaches Select (ohne Suche)

Das Feld .select-search-input ist optional — lässt man es weg, funktioniert die Komponente wie ein klassisches <select>, behält aber den Top Layer (kein Abschneiden in Modalen) und ein einheitliches Erscheinungsbild.

Planung
Ausstehend
In Bearbeitung
Abgeschlossen 
<div class="select-search">
  <button type="button" class="input select-search-trigger" popovertarget="status-select">
    <span>Planung</span>
  </button>

  <!-- Ohne .select-search-input = einfaches Select -->
  <div class="select-search-menu" popover id="status-select">
    <div class="select-search-list">
      <div class="select-search-option is-selected" data-value="planung">Planung</div>
      <div class="select-search-option" data-value="ausstehend">Ausstehend</div>
      <div class="select-search-option" data-value="in-bearbeitung">In Bearbeitung</div>
    </div>
  </div>

  <input type="hidden" name="status" class="select-search-hidden" value="planung">
</div>

Premium Multi Select

Auswahl mehrerer Optionen mit eingebauter Suche, Kategorisierung und interaktiven Optionskarten.

Beliebt
Sonstige
<div class="custom-select">
  <button type="button" class="custom-select-trigger" popovertarget="skills-select">
    <!-- Tags und Pfeil -->
  </button>

  <!-- [popover] = Top Layer: Menü wird nicht abgeschnitten, selbst im Modal -->
  <div class="custom-select-dropdown" popover id="skills-select">
    <!-- Suche -->
    <div class="custom-select-search">
      <input type="text" class="input" placeholder="Suchen...">
    </div>

    <div class="custom-select-list">
      <div class="custom-select-category">Kategorie</div>

      <!-- Optionskarte -->
      <label class="custom-select-option">
        <div class="flex-1">
          <div class="fw-bold">Option 1</div>
        </div>
        <input type="checkbox" class="form-check-input">
      </label>
    </div>
  </div>
</div>

Select im Modal (Top Layer)

Das Popover-Menü wird im Top Layer des Browsers gerendert — über einem geöffneten <dialog> und außerhalb seines scrollbaren Inhalts (.card-body hat overflow-y: auto). Dadurch wird die Optionsliste nie am Rand des Modals abgeschnitten.
