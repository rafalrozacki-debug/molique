Formular-Grundlagen

Kopierbereite Varianten der grundlegenden molique-Textfelder — schwebende Labels, native Validierung, Größen und ein selbstexpandierendes Textarea.

Schwebende Labels (Floating Labels)

Das Label befindet sich innerhalb des Feldes und wandert sanft nach oben, sobald geklickt oder zu tippen begonnen wird. 

<div class="form-floating">
  <!-- Das Attribut placeholder=" " ist für die CSS-Magie erforderlich! -->
  <input type="text" class="input" id="name" placeholder=" ">
  <label for="name">Vollständiger Name</label>
</div>

Native Validierung (Zero JS)

Nutzt die Pseudoklasse :user-invalid — die Fehlermeldung erscheint erst, wenn der Nutzer ein falsch ausgefülltes Feld verlässt.

Bitte geben Sie eine gültige E-Mail-Adresse ein. 
<div class="form-floating">
  <input type="email" class="input" id="email" placeholder=" " required>
  <label for="email">Geschäftliche E-Mail</label>

  <!-- Fehlermeldung (CSS zeigt sie automatisch dank :user-invalid) -->
  <div class="feedback-invalid">Ungültige E-Mail-Adresse.</div>
</div>

Größenvarianten (sm / lg)

Jedes Element mit der Klasse .input — Input, Select und Textarea — unterstützt dieselben Größenmodifikatoren. 

<input type="text" class="input input-sm" placeholder="Kompakt">
<input type="text" class="input" placeholder="Standard">
<input type="text" class="input input-lg" placeholder="Groß">

<select class="input input-sm">...</select>

Einzeiliges Textarea (Auto-Expand)

Das Feld nimmt zunächst die Höhe einer Zeile ein und erweitert sich nach Klick oder Eingabe auf mehrere Zeilen — ganz ohne JavaScript. 

<textarea
  class="input textarea-expandable"
  rows="1"
  placeholder="Zum Erweitern klicken…"
  style="--textarea-rows-expanded: 8;"
></textarea>
