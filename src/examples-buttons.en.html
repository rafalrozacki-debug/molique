Buttons

Ready-to-copy molique button variants — the full color range, grouping, ghost variants for dense tables, and a copy-to-clipboard button.

Button Variants

The base .btn class combined with color modifiers. 

<button class="btn btn-primary">Primary</button>
<button class="btn btn-secondary">Secondary</button>
<button class="btn btn-success">Success</button>

Button Group

Joins a series of buttons into a single line. Ideal for toolbars or view switchers. 

<div class="btn-group">
  <button class="btn btn-outline-dark">Option 1</button>
  <button class="btn btn-outline-dark">Option 2</button>
</div>

Action Buttons (Ghost)

The .btn-action class is designed for dense B2B interfaces (e.g. table rows). It removes the background and reduces padding while keeping the text legible. 

<button class="btn-action">Edit</button>
<button class="btn-action text-danger">Delete</button>

Copy to Clipboard Button

A built-in JS script for copying content — just add the .btn-copy class.

MOLIQUE2026 
<!-- The button must sit directly before the element with the text -->
<div class="position-relative">
  <button class="btn-copy">Copy</button>
  <div>Text that gets copied to the clipboard</div>
</div>

Special Variants

Modifiers added on top of the existing .btn/.btn-outline-* classes — a soft border, a stacked layout (icon above the label), and visual effects (glow, glass, 3D, shine, animated gradient). 

<button class="btn btn-outline-primary btn-outline-soft">Soft Outline</button>

<button class="btn btn-primary btn-stacked">
  <svg viewBox="0 0 256 256" fill="currentColor">...</svg>
  <span>Home</span>
</button>

<button class="btn btn-primary btn-glow">Glow</button>
<button class="btn btn-primary btn-3d">3D Push</button>
<button class="btn btn-primary btn-shine">Shine</button>
<button class="btn btn-gradient">Gradient</button>

.btn-glass needs a dark/colored background for the glass effect to be visible — that's why the preview below has its own background. 

<!-- Requires a dark/colored background underneath -->
<button class="btn btn-glass">Glass</button>
