Data Rows

Eine moderne Alternative zu Tabellen auf Basis von CSS Grid und Flexbox — ideal für Kunden-, Projekt- und Dateilisten in CRM-Systemen.

Datenzeilen (Data Rows)

Die Klasse .data-row nutzt CSS Grid, um Elemente in breiten Zeilen anzuordnen — eine großartige Alternative zu Tabellen in CRM-Systemen.

<!-- Zeile auf Basis von CSS Grid -->
<div class="data-row">
  <div class="fw-bold">Projektname</div>
  <div class="text-muted">Parameter</div>

  <!-- Status-Punkt -->
  <div><span class="status-dot status-pending">Ausstehend</span></div>

  <!-- Aktions-Buttons (mit vertikalen Trennlinien) -->
  <div class="data-row-actions btn-action-group with-dividers">
    <button class="btn-action">Bearbeiten</button>
    <button class="btn-action text-danger">Löschen</button>
  </div>
</div>

Kompakte Datenzeilen (List Items)

Die Variante .data-row-compact basiert auf Flexbox. Ideal für Seitenleisten, Download-Dateilisten oder Benachrichtigungen.

<div class="card border-0 shadow-sm">

  <!-- Kompakte Zeile -->
  <div class="data-row-compact">

    <!-- Icon (.icon-square für ein Quadrat hinzufügen) -->
    <div class="row-icon icon-square bg-danger text-white">
      <i class="icon-file-text"></i>
    </div>

    <!-- Inhalt (zu langer Text wird automatisch abgeschnitten) -->
    <div class="row-content">
      <div class="row-title">2026-bericht.pdf</div>
      <div class="row-details">0,4 MB von 0,8 MB</div>
    </div>

    <!-- Aktionen rechts -->
    <div class="row-actions">
      <button class="btn btn-action"><i class="icon-x"></i></button>
    </div>

  </div>

</div>

Einfache Liste (List Group)

Wenn .data-row zu viel und ein einfaches <ul> zu wenig ist — .list-group fasst Einträge zu einem einheitlichen Panel mit Rahmen zwischen den Zeilen zusammen.
