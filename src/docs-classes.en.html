4. Buttons and Badges
.btn .btn-primary .btn-danger The base button. Forces a 44px height on mobile (A11y).
.btn-xs .btn-sm .btn-lg .btn-xl Button size variants. Plain .btn (no modifier) is the middle variant (.btn-md).
.btn-group Groups buttons into one cohesive block (shared, overlapping borders, no double lines at the seams).
.btn-outline-primary An outline button (transparent background, colored border).
.btn-action A ghost button (no background or border). Perfect for tables and toolbars.
.btn-action-group .with-dividers Groups action buttons together, adding vertical dividers between them.
.badge .badge-success A small status label. Success
.btn-glow Adds a neon glow (box-shadow) on hover.
.btn-glass A glass effect (glassmorphism). Perfect on dark backgrounds and video.
.btn-3d A physical button that "presses in" when clicked. Requires the --btn-3d-shadow variable.
.btn-shine A sweeping light flash on hover.
.btn-gradient A flowing, animated background gradient.
5. Forms
.input A basic text field or select. Has a focus ring.
.input-sm .input-lg Size variants of .input - work on inputs, selects, and textareas. Plain .input (no modifier) is the middle variant.
.textarea-expandable A textarea collapsed to a single line. Expands on click (or when it has content) up to --textarea-rows-expanded rows, then scrolls internally. Requires the placeholder attribute.
.form-floating A container for floating labels (requires placeholder=" " on the input). -
.input-group .input-group-text Combines inputs, buttons, and text into one smooth rectangle.
.form-switch .form-switch-square .form-switch-outline An iOS-style toggle switch. Requires .form-switch-input and .form-switch-label.
.form-check-input .form-check-label Custom checkboxes and radio buttons built on CSS.
.form-pill .form-pill-group Checkboxes/radios that look like clickable pills (uses :has()). Variants: .pill-success, .pill-danger.
.custom-select .custom-select-trigger A premium multi-select built on the Popover API (top layer - not clipped inside modals). Contains .custom-select-dropdown, .custom-select-option. -
.select-search A single searchable select (combobox) built on the Popover API (top layer - not clipped inside modals). Requires JS for selection handling. The search field is optional - without .select-search-input it works like a regular select. -
.file-upload .file-upload-animated A drag & drop zone for files. The animated variant has a running border. -
.input-range .input-color Advanced inputs with a custom look. -
.feedback-invalid An error message. Appears automatically via :user-invalid. -

10. Navigation and Menus
.navbar .navbar-transparent The main navigation bar. The transparent variant becomes solid after scrolling (.is-scrolled). -
.navbar-sticky Add to .navbar to pin it to the top and enable the .is-scrolled/hide-on-scroll logic in molique-script.js. -
.navbar-offcanvas-toggle A checkbox hack for opening the mobile side menu with no JS. -
.mega-menu .mega-menu-trigger .mega-menu-content A wide dropdown menu built on <details> + CSS Anchor Positioning. Opens on click (desktop and mobile - zero JS), and automatically turns into an accordion on mobile. Column: .mega-menu-group > .mega-menu-col-title (optionally with an icon in .mega-menu-col-icon) + a list of .mega-menu-links. One grid "cell" can be replaced with a highlighted card .mega-menu-featured (with .mega-menu-featured-icon, -title, -text, -link) - e.g. to promote a new feature. -
.dropdown .dropdown-menu A classic dropdown menu built on the native <details> tag. Opens from the left by default - add .dropdown-menu-end to .dropdown-menu so it opens from the trigger's right edge instead (e.g. when it sits close to the right edge of the screen). -
.language-switch .language-switch-trigger A pill-shaped language switcher - the Dropdown Popover pattern: <button class="language-switch-trigger" popovertarget="ID"> + .dropdown-menu.language-switch-menu with the popover attribute (top layer). List items: .language-switch-item (containing .language-switch-flag with an SVG flag via <img src="img/flags/en.svg">, -name, optionally -check on the active language). Usually combined with .dropdown-menu-end, since it sits at the end of the navbar. -
.breadcrumb .breadcrumb-item Breadcrumb navigation showing the user's path. -
.pagination .pagination-modern Page pagination. The modern variant creates separated, rounded tiles. -
.topbar A narrow bar above the main navigation (often used for contact details). -
.progress-container-fixed .progress-bar-reading A reading progress bar pinned to the top of the screen. Requires the JS script (built into molique-script.js) to update the width while scrolling. -
.scroll-to-top A floating "go to top" button, appears after scrolling (adds .is-visible, handled by molique-script.js). -
