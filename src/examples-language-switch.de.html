Language Switch

Ein pillenförmiges Sprachauswahlmenü — der Auslöser öffnet das Menü als Popover im Top Layer (dasselbe Muster wie beim Dropdown Popover), null JavaScript. Flaggen sind winzige SVG-Dateien aus img/flags/ — Emoji-Flaggen werden unter Windows nicht angezeigt.

Sprachumschalter

Der Auslöser zeigt die Flagge und den Code der aktiven Sprache. Die Liste öffnet sich von der rechten Kante (.dropdown-menu-end), funktioniert also sicher als letztes Element in der Navbar. Die aktive Position hat ein Häkchen. Der Ordner img/flags/ enthält ausschließlich die im Projekt angebotenen Sprachflaggen (einzelne SVG-Dateien mit ~200 B, eingebunden über <img>) — jede lädt einmal und wird für die gesamte Website zwischengespeichert.
