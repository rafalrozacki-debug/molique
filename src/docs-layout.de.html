Grid & Layout

Drei Wege, Inhalte anzuordnen, plus ein komplettes Werkzeugset zur Positionierung. Das Wichtigste auf dieser Seite ist die goldene RWD-Regel im Abschnitt Fallstricke — der häufigste Fehler im gesamten Framework. Fertige Layouts: Beispiele.

1. Was wählen

Werkzeug Wann Wer entscheidet über die Spaltenzahl
.grid-auto Sich wiederholende Kacheln: Produktkarten, ein Leistungsraster, eine Referenzliste. Der Browser. Sie geben eine Mindestbreite der Kachel an.
.grid-cols-* Ein entworfenes Layout: 8 Spalten Text + 4 Spalten Sidebar. Sie, getrennt für jeden Breakpoint.
.d-flex Eine einzelne Elementreihe: eine Werkzeugleiste, ein Kartenkopf, eine Button-Gruppe. Nicht zutreffend — das ist eine einzige Achse.
.bento-grid Ein Mosaik unterschiedlich großer Kacheln — eine Startseite, ein Dashboard. Sie, über die Spannweite jeder Kachel.
Zwei Breakpoints, nicht fünf

molique hat nur md (ab 768px) und lg (ab 992px). Klassen ohne Präfix wirken von null aufwärts, beschreiben also die mobile Ansicht. Die Variante -md- überschreibt sie ab Tablet-Breite, -lg- ab Desktop-Breite. Weniger Schwellenwerte bedeuten weniger Stellen, an denen das Layout auseinanderfallen kann.

2. Auto-Grid

Das einfachste Werkzeug und meist die richtige Wahl. Sie deklarieren keine Spaltenzahl — Sie geben eine Mindestbreite der Kachel an, und der Browser passt so viele hinein, wie Platz ist. Beim Verschmälern des Fensters verringert er die Spaltenzahl von selbst, ganz ohne Media Queries. 

<div class="grid-auto">
  <div class="card">…</div>
  <div class="card">…</div>
  <div class="card">…</div>
</div>

<!-- Eigene Schwellenbreite -->
<div class="grid-auto" style="--grid-min: 240px;">…</div>

Kachel 2
Kachel 3
Kachel 4
Klasse Kachel-Schwelle Wofür
.grid-auto-sm 200px Icons, kleine Statistikkacheln.
.grid-auto 280px Standard — Karten mit Text.
.grid-auto-lg 350px Karten mit Foto, Artikel.
Warum es nie überläuft

Die Regel lautet minmax(min(100%, var(--grid-min)), 1fr). Die Funktion min() ist hier entscheidend: Ist das Fenster schmaler als die Kachel-Schwelle, gewinnt 100%, und die Kachel schrumpft auf die Bildschirmbreite. Ohne sie würde sie starr bei 280px bleiben und über den Rand des Smartphones hinausragen.

3. 12-Spalten-Raster

Für den Fall, dass das Layout entworfen, nicht berechnet werden soll. Das Elternelement erhält die Spaltenzahl, die Kinder die Spannweite. Die Klassen existieren in drei Varianten: ohne Präfix (mobil), mit -md- und mit -lg-. 

<!-- Mobil: eine Spalte (Standard). Desktop: 8 + 4 -->
<div class="grid-md-cols-12 gap-4">
  <article class="col-md-span-8">Inhalt</article>
  <aside class="col-md-span-4">Sidebar</aside>
</div>
grid-cols-1 ist nicht nötig

Die Klassen .grid-md-cols-* und .grid-lg-cols-* sind standardmäßig ein einspaltiges Raster unterhalb ihrer eigenen Schwelle — das Hinzufügen von .grid-cols-1 ändert nichts. Früher war es erforderlich, und sein Fehlen erzeugte ein hinterhältiges Symptom: Das Layout sah gut aus, aber gap funktionierte auf dem Smartphone nicht mehr, weil das Element in diesem Moment kein Grid war.

Familie Bereich Was sie macht
.grid — Aktiviert das Raster, ohne Spalten festzulegen.
.grid-cols-* 1–12 Spaltenzahl des Elternelements. Varianten: .grid-md-cols-*, .grid-lg-cols-* — beide standardmäßig einspaltig unterhalb ihrer eigenen Schwelle.
.col-span-* 1–12 Wie viele Spalten ein Kind einnimmt. Varianten: .col-md-span-*, .col-lg-span-*. Nicht auf Mobilgeräten verwenden — siehe Fallstrick Nr. 1.
.col-start-* 1–12, auto Ab welcher Spalte ein Element beginnt. Varianten: .col-md-start-*, .col-lg-start-*.
.offset-* 0–11 Klassische Verschiebung um N Spalten. Varianten: .offset-md-*, .offset-lg-*.
.gap-* 0–5 Abstand zwischen Elementen. Variante: .gap-md-*. Funktioniert auch im Flexbox.
col-start oder offset

Beide erreichen dasselbe auf zwei Arten. .col-start-4 bedeutet „in der vierten Spalte beginnen" — eine absolute Position, gut lesbar beim Entwerfen eines Layouts. .offset-3 bedeutet „um drei verschieben" — bequemer, wenn Sie Code aus Bootstrap übertragen. Entscheiden Sie sich für eines und bleiben Sie innerhalb eines Projekts dabei.

4. Flexbox

Für eine einzelne Achse: eine Leiste mit Logo und Buttons, ein Kartenkopf, eine Fußzeile mit Aktionen. Für das Seitenlayout verwenden Sie ein Raster.

Klasse Was sie macht
.d-flex Aktiviert Flexbox. Standardmäßig als Reihe.
.flex-column Ordnet als Spalte an. Varianten: .flex-md-column, .flex-md-row — z. B. Spalte auf Mobilgeräten, Reihe auf dem Desktop.
.flex-wrap Erlaubt Elementen, in die nächste Zeile umzubrechen.
.justify-content-start Verteilung entlang der Hauptachse. Außerdem: .justify-content-center, .justify-content-end, .justify-content-between.
.align-items-center Ausrichtung quer zur Achse. Außerdem: .align-items-start, .align-items-end, .align-items-stretch.
.align-self-center Dasselbe, aber für ein einzelnes Kind. Außerdem: .align-self-start, .align-self-end, .align-self-stretch.
.d-block Die übrigen Anzeigemodi: .d-inline-block, .d-grid, .d-none.
.d-md-none Sichtbarkeit abhängig von der Breite. Auch .d-md-block, .d-md-flex — z. B. ein Menü, das erst ab Tablet-Breite gezeigt wird.

5. Positionierung und Größen

Klasse Gruppe Was sie macht
.position-relative Position Ein Bezugspunkt für Kinder. Außerdem: .position-absolute, .position-fixed, .position-sticky.
.top-0 Kanten Anheften an eine Kante: .bottom-0, .left-0, .right-0. .inset-0 heftet an alle gleichzeitig.
.top-50 Zentrierung Zusammen mit .left-50 und .translate-middle zentriert ein Element im Elternelement. Einzeln: .translate-middle-x, .translate-middle-y.
.z-10 Ebenen Stapelreihenfolge innerhalb eines Abschnitts: .z-0, .z-20, .z-30. Für globale Komponenten dienen die Variablen --z-index-* — siehe Fallstrick Nr. 3.
.w-100 Breite Auch .w-25, .w-50, .w-75, .w-auto sowie Varianten .w-md-*. .mw-100 begrenzt das Maximum — Rettung für Bilder, die das Layout sprengen.
.h-100 Höhe Volle Höhe des Elternelements. .vh-100 und .min-vh-100 beziehen sich auf das Fenster.
.breakout-mobile Breite Reißt ein Element auf Mobilgeräten (unterhalb von 768px) aus dem Padding des .container heraus, bis zum Bildschirmrand — Karussells, Galerien, Hero-Fotos im Artikelinhalt. Auf dem Desktop ohne Effekt. Keine Konfiguration nötig, muss den Padding-Wert des Elternelements nicht kennen.
.text-center Text Inhaltsausrichtung: .text-start, .text-end.
.fade-bottom Effekt Ausblenden des Inhalts am unteren Rand statt eines harten Schnitts. Farbe: --fade-color, Höhe: --fade-height. 
<!-- Ein Element perfekt in der Mitte des Elternelements -->
<div class="position-relative" style="height: 200px">
  <span class="position-absolute top-50 left-50 translate-middle">Mitte</span>
</div>
<!-- Das Karussell berührt auf Mobilgeräten die Bildschirmränder,
     kehrt auf dem Desktop zur .container-Breite zurück -->
<div class="container">
  <p>Ein gewöhnlicher Absatz mit Rand...</p>
  <div class="carousel breakout-mobile">
    <!-- ... -->
  </div>
</div>

6. Bento Grid

Ein Mosaik unterschiedlich großer Kacheln — ein von Produktseiten und Dashboards bekanntes Layout. Das Elternelement legt das Raster fest, und Sie strecken ausgewählte Kacheln über mehr Spalten oder Zeilen. 

<div class="bento-grid">
  <div class="card bento-col-2 bento-row-2">Große Kachel</div>
  <div class="card">Klein</div>
  <div class="card bento-row-2">Vertikal</div>
  <div class="card bento-col-2">Horizontal</div>
</div>
Klasse Was sie macht
.bento-grid Das Mosaikraster. Dichtevarianten: .bento-grid-3, .bento-grid-4.
.bento-col-2 Eine Kachel über zwei Spalten. Breiter: .bento-col-3.
.bento-row-2 Eine Kachel über zwei Zeilen. Höher: .bento-row-3.

7. Fallstricke

1 GOLDENE REGEL: .col-span-* auf Mobilgeräten

Der häufigste Fehler im gesamten Framework. Klassen ohne Präfix wirken von null aufwärts, also auch auf dem Smartphone. Das Elternelement hat dort .grid-cols-1 — eine Spalte — daher weist .col-span-12 das Kind an, zwölf Spalten in einem Raster einzunehmen, das nur eine hat. Das Layout bricht auseinander.

In einem einspaltigen Raster nimmt ein Element ohnehin die volle Breite ein. Deklarieren Sie die Spannweite ausschließlich über die Varianten -md- und -lg-. 

<!-- FALSCH - col-span-12 wirkt auch auf dem Smartphone -->
<div class="grid-md-cols-12">
  <div class="col-span-12 col-md-span-8">…</div>
</div>

<!-- RICHTIG - die volle Breite auf Mobilgeräten ergibt sich von selbst -->
<div class="grid-md-cols-12">
  <div class="col-md-span-8">…</div>
</div>
2 Ein starres Raster, wo Auto-Grid ausreicht

Eine Kartenliste braucht kein entworfenes Layout. Die Schreibweise grid-cols-1 grid-md-cols-2 grid-lg-cols-3 sind drei zu pflegende Entscheidungen und drei Stellen, an denen ein Fehler passieren kann. .grid-auto liefert denselben Effekt mit einer einzigen Klasse und passt sich auch Zwischenbreiten an, die Sie nicht vorgesehen haben.

3 Eigene Zahlen bei z-index

Die Klassen .z-0–.z-30 ordnen Ebenen innerhalb eines einzelnen Abschnitts — z. B. Inhalt über einer Overlay auf einem Foto. Verwenden Sie sie nicht für globale Komponenten: Modal, Toast und Dropdown haben eine feste Hierarchie in den Variablen --z-index-*. Dort abkürzend z-index: 9999 einzutragen endet damit, dass ein Modal an einer ganz anderen Stelle der Website unter der Navbar landet.

Vollständige Skala: CSS-Variablen.

4 Ein Foto, das das Raster sprengt

Ein Rasterelement schrumpft standardmäßig nicht unter die Größe seines Inhalts. Ein großes Foto oder eine lange Zeichenkette ohne Leerzeichen (eine URL, eine Kontonummer) sprengt daher die Spalte und löst eine horizontale Bildlaufleiste für die gesamte Seite aus. Bei Bildern genügt .mw-100.

5 .breakout-mobile zu tief verschachtelt

Die Technik beruht darauf, dass margin-left: 50% relativ zur Breite des direkten Elternelements berechnet wird, und dieses muss im Fenster zentriert sein, so wie .container (also margin-inline: auto haben). Das Element funktioniert korrekt als direktes Kind von .container — aber tiefer verschachtelt, z. B. in einem .card-body innerhalb des Containers, wird es relativ zur Breite der Karte berechnet, nicht zum Fenster, und landet verschoben/abgeschnitten, statt den Bildschirmrand zu berühren. Verschieben Sie die Klasse auf die nächste .container-Ebene, oder umhüllen Sie das problematische Element mit einem zusätzlichen <div> direkt darin.
