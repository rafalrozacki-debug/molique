Carousel (Slider)

A basic carousel. No need for heavy libraries like Slick or Swiper — it's remarkably smooth on touch devices.

<div class="carousel">
  <button class="carousel-nav carousel-prev">‹</button>
  <button class="carousel-nav carousel-next">›</button>

  <div class="carousel-track">
    <!-- Set min-width to control how many slides are visible at once -->
    <div class="carousel-slide" style="min-width: 100%;">
      <div class="card">Slide 1 content</div>
    </div>
    <div class="carousel-slide" style="min-width: 100%;">
      <div class="card">Slide 2 content</div>
    </div>
  </div>
</div>

Hero Carousel (Background Sync)

An advanced carousel variant where the whole container's background smoothly changes depending on the currently visible slide.

Architecture

Construction 

<!-- Add the carousel-bg-sync class -->
<div class="carousel carousel-bg-sync">
  <div class="carousel-bg-overlay"></div>

  <div class="carousel-track">
    <!-- The data-bg attribute defines the background for a given slide -->
    <div class="carousel-slide" data-bg="img/slide1.jpg">
      <h2>Heading 1</h2>
    </div>
    <div class="carousel-slide" data-bg="img/slide2.jpg">
      <h2>Heading 2</h2>
    </div>
  </div>
</div>
