Basic Charts

Ready-to-copy charts built 100% on plain HTML/CSS/SVG — sparklines, radial rings, activity heatmaps, area charts, and pie charts.

Sparklines (Bar Charts)

Built on Flexbox. Bar height is passed from the backend via the --val CSS variable. 

<div class="r-chart-wrapper" data-type="sparkline" data-values="[20, 50, 80]">
  <div class="chart-sparkline">
    <div class="sparkline-bar" style="--val: 20%;"></div>
    <div class="sparkline-bar" style="--val: 50%;"></div>
    <div class="sparkline-bar" style="--val: 80%;"></div>
  </div>
</div>

Heatmap (Activity Maps)

Built on CSS Grid and aspect-ratio. The --val variable (from 0.0 to 1.0) controls the background color's opacity (Alpha channel). 

<div class="chart-heatmap grid-cols-10">
  <!-- The --val value is the Alpha channel (opacity), from 0.0 to 1.0 -->
  <div class="heatmap-cell" style="--val: 0.1;"></div>
  <div class="heatmap-cell" style="--val: 0.8;"></div>
  <div class="heatmap-cell" style="--val: 1.0;"></div>
</div>
