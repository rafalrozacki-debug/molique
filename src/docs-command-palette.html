Paleta poleceń

Pole wyszukiwania z listą wyników, otwierane przyciskiem albo skrótem. Skok do strony, wykonanie akcji, znalezienie rekordu bez klikania po menu. Stoi na natywnym <dialog>, więc warstwę nad stroną, pułapkę fokusa i Esc daje przeglądarka.

1. Wypróbuj

Otwórz przyciskiem albo przez Ctrl + K. Wpisz „kontrahent”, a znajdziesz stronę po tagu. Wpisz „ko”, a po chwili dojdą wyniki udające odpowiedź serwera.

2. Markup

Pozycje zapisane w HTML filtrują się na miejscu: bez polskich znaków, po widocznym tekście i po rdzeniach z data-tags. Pozycja to link albo przycisk, oba wyglądają tak samo. 

<button data-command-palette-open="#palette">Szukaj</button>

<dialog class="command-palette" id="palette" aria-label="Szukaj"
        data-command-palette-hotkey="k">
  <div class="command-palette-header">
    <input class="command-palette-input" placeholder="Szukaj...">
  </div>
  <div class="command-palette-list">
    <div class="command-palette-group">
      <div class="command-palette-group-label">Strony</div>
      <a class="command-palette-item" href="/clients" data-tags="kontrahen firm">Klienci</a>
      <button class="command-palette-item" type="button" data-value="new">Nowe zlecenie</button>
    </div>
  </div>
</dialog>

3. Klasy

Klasa Co robi
.command-palette Na <dialog>. Szerokość: --command-palette-width (640px). Na telefonie zajmuje cały ekran.
.command-palette-header Rząd z ikoną i polem.
.command-palette-input Pole. Rolę combobox i powiązanie z listą nadaje skrypt.
.command-palette-list Przewijana lista wyników.
.command-palette-group Grupa pozycji. Znika, gdy nic w niej nie pasuje.
.command-palette-group-label Nagłówek grupy.
.command-palette-item Pozycja: <a> albo <button>. data-tags to rdzenie do szukania, data-value trafia do zdarzenia.
.command-palette-item-label Główny tekst pozycji, ucinany wielokropkiem.
.command-palette-item-meta Dopisek po prawej: NIP, dział, skrót.
.command-palette-footer Opcjonalny pasek z podpowiedziami klawiszy. Na ekranie dotykowym znika.
.command-palette-close Przycisk zamykania. Tworzy go skrypt, a widać go tylko na ekranie dotykowym i do 768 px, gdzie nie ma Esc ani tła do kliknięcia.
.command-palette-empty Komunikat pustego stanu, oczekiwania i błędu. Tworzy go skrypt.
.command-palette-remote Kontener wyników z serwera. Tworzy go skrypt.

4. Wyniki z serwera

molique nie ma backendu, więc zapytanie wysyła Twój kod. Wyniki przychodzą przez zdarzenie, nie przez funkcję: moduł ładuje się asynchronicznie, a nasłuch możesz podpiąć w dowolnej chwili, także zanim moduł dotrze. 

// wynik: { label, href?, meta?, group?, value? }
document.addEventListener('command:search', (e) => {
  const { query, signal, respond } = e.detail;
  respond(
    fetch('/api/search?q=' + encodeURIComponent(query), { signal })
      .then((response) => response.json())
  );
});
  • respond() przyjmuje tablicę albo Promise. Zapytanie zostaje przerwane przez signal, gdy ktoś pisze dalej, a spóźniona odpowiedź na starsze zapytanie jest ignorowana.
  • Wszystko trafia na stronę jako tekst, więc rekord o nazwie <img onerror=...> zostaje nazwą. Adres inny niż http(s) jest odrzucany, a pozycja staje się przyciskiem bez linku.
  • Uprawnienia sprawdza serwer. Paleta pokaże to, co dostanie.

Wybór pozycji ogłasza command:select. preventDefault() powstrzymuje przejście pod link: 

document.addEventListener('command:select', (e) => {
  if (e.detail.value === 'new') {
    e.preventDefault();
    openOrderForm();
  }
});

5. Atrybuty i API

Atrybut Co robi
data-command-palette-open="#id" Na dowolnym przycisku: otwiera wskazaną paletę.
data-command-palette-hotkey="k" Na dialogu: Ctrl/Cmd + klawisz otwiera i zamyka. Opcjonalny, bo framework nie powinien sam zajmować klawiszy. Nie działa w edytorze contenteditable ani nad innym otwartym oknem.
data-command-palette-min="2" Od ilu znaków pytać serwer.
data-command-palette-debounce="200" Ile milisekund czekać po ostatnim znaku.
data-command-palette-empty="..." Własny tekst pustego stanu. Domyślny idzie za lang dokumentu (PL/EN/DE).
MoliqueCommandPalette.open(el) Otwiera z kodu. Także .close(el). Moduł ładuje się asynchronicznie, więc wołaj to po kliknięciu, nie przy starcie strony.

6. Klawiatura

Klawisz Co robi
↑ ↓ Ruch po wynikach, z zawijaniem.
Home, End Pierwszy i ostatni wynik, gdy pole jest puste. Przy tekście w polu należą do kursora.
Enter Wybiera podświetloną pozycję.
Esc Zamyka i oddaje fokus temu, co paletę otworzyło.

Fokus zostaje w polu, więc pisanie działa cały czas, a aria-activedescendant mówi czytnikowi ekranu, która pozycja jest podświetlona. Ta sama obsługa działa w Searchable Select i Multi Select.

7. Pułapki

Tagi to rdzenie, nie słowa.

Rdzeń ma łapać odmianę: kontrahen znajdzie „kontrahenta” i „kontrahentów”, a kontrahent nie znajdzie „kontrahenci”.

Nie wołaj API przy starcie strony.

MoliqueCommandPalette może jeszcze nie istnieć. Do wyników używaj zdarzenia, a do otwierania data-command-palette-open.

Nowe zapytanie zawsze wraca na górę listy.

Enter ma znaczyć najlepsze trafienie, nie pozycję z poprzedniego szukania. Wyniki dochodzące później nie ruszają tego, co ktoś już wskazał strzałkami.
