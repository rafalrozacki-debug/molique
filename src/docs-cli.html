Na npm

CLI molique-jit

Wiersz poleceń, którym obsługujesz silnik molique JIT: budowanie, tryb nasłuchujący na żywo, konfiguracja - plus 8 generatorów gotowych bloków HTML.

1. Instalacja

Pakiet jest opublikowany na npm jako molique-jit. Zwykle wystarczy zależność deweloperska: 

npm install --save-dev molique-jit

Albo bez instalacji, jednorazowo przez npx: 

npx molique-jit init
npx molique-jit build

Strona pakietu: npmjs.com/package/molique-jit. Kod źródłowy jest jawny w repozytorium: github.com/rafalrozacki-debug/molique.

2. Plik konfiguracyjny molique.config.mjs

Komenda init tworzy ten plik za Ciebie, z komentarzami przy każdym polu. Pełny, ręcznie napisany przykład: 

// molique.config.mjs
export default {
  // Gdzie szukać nazw klas.
  content: ['**/*.html', '**/*.php'],

  // Gdzie zapisać wynikowy CSS.
  output: 'css/molique-jit.css',

  // WYŁĄCZNIE klasy specyficzne dla Twojego projektu (np. składane w PHP).
  // Klas runtime'owych molique (toasty, karuzela, stany .is-*) NIE trzeba
  // tu wpisywać - silnik dołącza je automatycznie.
  safelist: ['badge-success', 'badge-danger'],

  minify: true,
};

Jeśli masz kilka niezależnych stron w jednym projekcie (np. główną witrynę i osobny landing kampanii), pole targets zastępuje content/ output powyżej i buduje każdy cel osobno - landing dostaje własny, mały plik CSS, bez reszty: 

export default {
  targets: [
    { content: ['src/**/*.html'], output: 'css/molique-jit.css' },
    { content: ['landing-kampania.html'], output: 'css/landing-kampania.css' },
  ],
};
Pole Domyślnie Opis
content ['**/*.html', '**/*.php'] Gdzie szukać klas (wzorce glob).
output css/molique-jit.css Ścieżka pliku wynikowego.
safelist [] Klasy Twojego projektu, których skan mógłby nie znaleźć (np. sklejane w backendzie).
minify true Obecnie efektywnie bez znaczenia - źródłowe dane są już skompresowane u źródła.
targets - Lista niezależnych buildów; gdy podana, zastępuje content/output.

3. Komendy silnika

Binarka nazywa się molique-jit (nie samo molique), żeby nie kolidować z innymi narzędziami o krótszej nazwie. CLI rozumie polecenia po angielsku, ale też ich polskie i niemieckie odpowiedniki - wygodne w zespołach, które na co dzień mówią jednym z tych języków.

Angielski (kanoniczny) Polski alias Niemiecki alias Co robi
init start start Tworzy plik molique.config.mjs ze wzorcową konfiguracją.
build buduj bauen Jednorazowo kompiluje CSS do pliku(ów) wyjściowego(ych).
watch obserwuj beobachten Nasłuchuje zmian plików i przebudowuje na żywo (~50ms debounce).
--minify / -m --minifikuj --minifizieren Wymusza kompresję wyjścia.
--config / -c --konfiguracja --konfiguration Wskazuje własną ścieżkę pliku konfiguracyjnego.

Wszystkie trzy warianty językowe robią dokładnie to samo:

npx molique-jit init
npx molique-jit build --minify
npx molique-jit watch --config ./custom.config.mjs
npx molique-jit start
npx molique-jit buduj --minifikuj
npx molique-jit obserwuj --konfiguracja ./custom.config.mjs
npx molique-jit start
npx molique-jit bauen --minifizieren
npx molique-jit beobachten --konfiguration ./custom.config.mjs

Kody wyjścia

build kończy się kodem 0 przy sukcesie i 1 przy błędzie (np. gdy plik konfiguracyjny wskazuje nieistniejący folder) - wygodne do spięcia z CI, np. jako krok przed publikacją.

4. Generatory komponentów: make:*

Osobna rodzina komend, niezależna od budowania CSS. Każda uruchamia w terminalu interaktywny kreator (strzałki + Enter), a na końcu wypisuje gotowy, wklejalny blok HTML - zgodny co do znaku z prawdziwymi, działającymi przykładami z tej dokumentacji. Sama komenda make:component niczego nie generuje - wypisuje spis wszystkich dostępnych generatorów, żeby nie trzeba było pamiętać nazw: 

npx molique-jit make:component
Komenda Polski alias Niemiecki alias Generuje
make:modal zrob:modal mache:modal Modal (<dialog>) - Standard / Confirm / Context
make:layout zrob:uklad mache:layout Szkielet strony - Admin Dashboard / Hero (Simple + Cutout) / Bento Grid
make:nav zrob:nawigacje mache:nav Navbar - offcanvas, 3 warianty tła, opcjonalnie Mega Menu / Theme Switch / Language Switch
make:table zrob:tabele mache:tabelle Tabela B2B z automatycznym data-label na mobile
make:chart zrob:wykres mache:diagramm Wykres CSS/SVG - Radial Bar / Funnel / Pipeline / Stock Bar
make:form zrob:formularz mache:formular Formularz - Floating Labels / Klasyczny, opcjonalnie Searchable Select / Premium Multi Select / Drag & Drop File Upload
make:popover zrob:popover mache:popover Menu kontekstowe .popover-context (CSS Anchor Positioning)
make:widget zrob:widget mache:widget Speed Dial / Before-After Slider / Stepper / Share Bar
make:component - Wypisuje ten spis (nie jest generatorem)

Flaga -n, --count

Każdy generator, który tworzy listę o zmiennej długości (pozycje menu, wiersze tabeli, etapy wykresu…), przyjmuje -n, --count <liczba> - pomija TYLKO pytanie „ile?", reszta kreatora (etykiety, warianty, kolory) nadal działa interaktywnie: 

npx molique-jit make:modal
npx molique-jit make:table --count 5

Na koniec każdego generatora wybierasz, czy kod ma trafić na ekran konsoli (do skopiowania myszką) czy od razu zapisać się do pliku - narzędzie nigdy nie nadpisuje istniejącego pliku bez wyraźnego potwierdzenia.
