Karten

Vier Kartentypen für unterschiedliche Zwecke plus ein vollständiges Set an Hover-Effekten. Fertige Layouts finden Sie in den Beispielen; Datentabellen behandelt eine separate Seite, Tabellen & Listen.

1. Welche Karte

Alle vier sind einfache Boxen mit Rahmen und Schatten — der Unterschied liegt im Zweck und darin, was jede von sich aus hinzufügt.

Klasse Wofür Was sie hinzufügt
.card Ein universeller Container: ein Dashboard-Panel, ein Formular, der Inhalt eines Modals. Nichts — eine reine Oberfläche.
.featured-box Präsentation eines Merkmals oder einer Dienstleistung auf einer Angebotsseite. Einen dicken oberen Rahmen und Platz für ein Icon.
.thumb-info Portfolio, Galerie, Kategorie-Kacheln. Ein Hintergrundfoto und ein Titel-Overlay, das beim Hover erscheint.
.testimonial Eine Kundenbewertung. Ein Layout für Zitat, Bewertung und Autor mit Avatar.
Header

Karteninhalt. Header und Footer sind optional.

Footer
⚡

Featured Box

Ein dicker oberer Rahmen in der Akzentfarbe.

2. Die klassische Karte

Drei Bereiche, alle optional. Ein reines .card ist bereits vollständig — Header und Footer fügen Sie nur hinzu, wenn Sie etwas hineinzupacken haben. 

<div class="card">
  <div class="card-header">Titel</div>
  <div class="card-body">Inhalt…</div>
  <div class="card-footer">Aktionen</div>
</div>
Klasse Was sie tut
.card Eine --bg-surface-Oberfläche, ein Rahmen, Rundung und Schatten. Schneidet den Inhalt zu, sodass ein bildschirmfüllendes Bild von selbst abgerundete Ecken bekommt.
.card-header Eine Titelleiste mit Trennlinie.
.card-body Der Hauptinhalt mit Innenabstand. Ohne ihn klebt der Inhalt an den Rändern — siehe Fallstrick Nr. 1.
.card-footer Ein Footer für Buttons und Metadaten; gedämpfter Hintergrund.
Eine Karte als Modal-Inhalt

Innerhalb von <dialog class="modal-dialog"> ist es genau .card, das dem Fenster Header, Inhalt und Button-Leiste gibt. Es gibt keine separaten Modal-Klassen für diese Bereiche — siehe Modale, Tabs & Akkordeons.

3. Featured Box und Bildkarten

Featured Box

Eine Karte für ein einzelnes Produktmerkmal. Das Icon und der dicke obere Rahmen machen sie zu einem rhythmisch wiederholbaren Element — drei oder vier nebeneinander in einem Raster. 

<div class="featured-box">
  <div class="featured-box-icon">⚡</div>
  <h4>Geschwindigkeit</h4>
  <p>Beschreibung des Merkmals…</p>
</div>

Bildkarten

Ein Foto mit einem Overlay, das beim Hover einfährt. Benötigt zwei Ebenen: .thumb-info umhüllt das Ganze und schneidet das Foto zu, während .thumb-info-wrapper im Inneren nur das Bild hält. Ohne diese zweite Ebene gibt es beim Hover nichts zu skalieren. 

<a href="#" class="thumb-info">
  <span class="thumb-info-wrapper">
    <img src="foto.jpg" alt="">
  </span>
  <span class="thumb-info-title">Projektname</span>
</a>
Klasse Komponente Was sie tut
.featured-box Featured Box Eine Karte mit Akzentrahmen oben.
.featured-box-icon Featured Box Ein rundes Feld für ein Icon oder Emoji.
.thumb-info Bildkarte Die Hülle; schneidet das Foto zu und hält das Overlay.
.thumb-info-wrapper Bildkarte Die Ebene mit dem Foto — sie ist es, die beim Hover skaliert.
.thumb-info-title Bildkarte Die Beschriftung auf dem Overlay.
.thumb-info-bottom Bildkarte Variante: Beschriftung an der unteren Kante.
.thumb-info-center Bildkarte Variante: Beschriftung zentriert.
.thumb-info-light Bildkarte Ein helleres Overlay — für dunkle Fotos.

4. Referenzen

Kundenbewertung: Zitat, Bewertung und Autor. Die Bewertung ist .testimonial-stars, derselbe Mechanismus wie .star-rating im Shop — den Wert übergeben Sie per Variable --rating, nicht per Klasse. 

<div class="testimonial">
  <div class="testimonial-stars" style="--rating: 5;"></div>
  <p class="testimonial-quote">Die Einführung lief reibungsloser als erwartet.</p>
  <div class="testimonial-author">
    <img class="testimonial-avatar" src="avatar.jpg" alt="">
    <div>
      <div class="testimonial-name">Anna Kowalska</div>
      <div class="testimonial-role">Betriebsleiterin</div>
    </div>
  </div>
</div>
Klasse Was sie tut
.testimonial Die Hülle der Bewertung.
.testimonial-stars Die Bewertung. Gesteuert über die Variable --rating (0–5, Bruchteile füllen einen Stern teilweise).
.testimonial-quote Der Inhalt der Aussage.
.testimonial-author Der Footer: Avatar plus Personendaten.
.testimonial-avatar Das Foto des Autors, kreisförmig zugeschnitten.
.testimonial-name Vor- und Nachname.
.testimonial-role Position oder Unternehmen.
Mehrere Bewertungen nebeneinander

Packen Sie Referenzen in ein .carousel — Sie erhalten einen per Touch scrollbaren Slider, ohne etwas zu schreiben. Details in Karussells & Lightbox.

5. Effekte und Überlappen auf ein Hero

Hover

Die Effekte bewegen ausschließlich transform und opacity, werden also von der GPU berechnet und lösen keine Neuberechnung des Seitenlayouts aus. Sie lassen sich auf einem Element kombinieren.

Klasse Effekt Benötigt JS
.hover-spring Federndes Abprallen beim Hover. nein
.hover-gpu-shadow Wachsender Schatten ohne Animation von box-shadow. nein
.hover-scale Vergrößerung. Stärke über --hover-scale. nein
.hover-shadow Anheben mit Schatten. Höhe: --hover-y. nein
.hover-tilt Feste 3D-Neigung beim Hover. nein
.tilt-card Neigung, die dem Cursor folgt. Bei Touch schaltet sich das Modul selbst ab — spart Akku. ja

Überlappen auf den Abschnitt darüber

Ein klassisches Layout einer Angebotsseite: eine Karte überlappt die untere Kante eines Heroes. Das ist ein negativer oberer Rand — .overlap-container gibt einen Standardwert, und die Varianten erlauben, ihn auf die Höhe der Karte abzustimmen.

Klasse Was sie tut
.overlap-container Zieht das Element nach oben. Auf Mobilgeräten ist die Verschiebung kleiner, damit die Karte die Hero-Überschrift nicht verdeckt.
.overlap-up-50 Zieht um ca. 50px nach oben.
.overlap-up-100 Zieht um ca. 100px nach oben.
.overlap-up-150 Zieht um ca. 150px nach oben — für hohe Karten.

6. Fallstricke

1 Inhalt direkt in .card geworfen

Ein reines .card hat keinen Innenabstand — das ist beabsichtigt, damit ein Bild oder eine Tabelle bis an die Ränder reichen können. Direkt eingefügter Text klebt dadurch am Rahmen. Umhüllen Sie ihn mit .card-body oder fügen Sie der Karte eine Abstandsklasse hinzu, z. B. .p-4. 

<!-- FALSCH - Text direkt am Rahmen -->
<div class="card">Inhalt</div>

<!-- RICHTIG -->
<div class="card"><div class="card-body">Inhalt</div></div>
<div class="card p-4">Inhalt</div>
2 Bildkarte ohne .thumb-info-wrapper

Ein direkt in .thumb-info eingefügtes Bild wird korrekt angezeigt, der Fehler ist also leicht zu übersehen — beim Hover passiert einfach nichts. Skaliert wird die Ebene .thumb-info-wrapper, nicht das <img> selbst; ohne sie gibt es nichts zu animieren.

3 Bewertung im Klassennamen zusammengesetzt

Es ist verlockend, im Template class="stars-4" zu generieren. Ein solcher Name existiert nicht als Literal im Quellcode, weder PurgeCSS noch die Suche im Editor finden ihn. Die Bewertung reist per Variable, genau damit ein Wert aus dem Backend keine neuen Klassen erzeugt. 

<!-- FALSCH -->
<div class="testimonial-stars stars-<?= $bewertung ?>">

<!-- RICHTIG -->
<div class="testimonial-stars" style="--rating: <?= $bewertung ?>;">
4 Eine auf ein Hero gezogene Karte versteckt sich darunter

.overlap-container hebt das Element per negativem Rand an und gibt ihm einen z-index, aber wenn der Hero-Abschnitt einen eigenen Stacking-Kontext hat (z. B. über position und einen höheren z-index), landet die Karte dahinter. Halten Sie sich an die Skala der --z-index-*-Variablen, statt eigene Zahlen einzutragen.
